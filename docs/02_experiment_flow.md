## 目標と現行経路

計画書の手順は、事前テスト、必要な用語の学習、再テスト、未達用語の再学習、満点または中断後のアンケートという流れ。現行4仮説の測定上の回数・対象経路は[01](01_research_requirements.md)と[12](12_evaluation_metrics.md)に定める。評価指標版変更は画面遷移・回答・進行条件を変えない。

仕様版48で導入した事前アンケートと4用語版の条件は、それぞれ[事前アンケート](49_presurvey_baseline.md)と[4用語版フロー](51_four_topic_foundation_mode.md)を参照する。仕様版50で理解度質問・4用語版表記・教材量設問文を更新し、仕様版51で4用語版の問題とアンケートをインストラクションチューニング表記へ戻した。仕様版52で教材量設問文を再度簡潔化し、仕様版53で4用語版v3と全テスト満点後の早期終了を統合した。旧仕様版の記録と現行フローを区別する。

仕様版42では新規登録・出題・学習・集計は通常版だけを扱い、問題バンクの切替経路はなかった。旧条件の保存データ削除は通常の起動・seedから分離し、[専用削除手順](../backend/scripts/purge_easy_mode_data.py)で明示実行する。

## 仕様版42の履歴フロー

1. start → consentで参加コードA/Bを受け取り、新しい参加者を作成する。
2. presurveyで用語事前知識6項目と普段のAI利用2項目へ回答し、必須8項目を保存してからpretestへ進む。未回答のまま事前テストは開始できない。
3. pretestで各用語の設問1だけ（計3問）へ回答する。各回答後に本人の選択と正誤を確認し、3問完了後に固定採点する。テスト全体の結果画面は表示しない。
4. 学習対象があればlearning_targetsから用語順に学習する。学習対象がなければ内部final_testへ進む。
5. 学習はAI教材＋固定確認問題。1用語・1セッションあたりの回答上限は既存仕様に従う。正解または上限到達後に次の対象へ進み、不正解の用語は未達のまま残る。
6. 全対象の学習後、retestで各用語の設問1だけ（計3問）へ回答し、各回答後に本人の選択と正誤を確認する。採点済みバッチは未回答を含めて1回とし、全問未回答は採点しない。初回未達は既存の再学習経路へ進み、最終回未達は未達のままsurveyへ進む。満点ならsurveyへ進む。
7. 事前テストで満点だった参加者は内部final_testへ進み、各用語の設問1だけ（計3問）へ回答後に本人の選択と正誤を確認する。採点結果に応じ、満点ならsurvey、不正解・未回答があれば既存の学習後retest_v2へ進む。
8. survey（事後アンケート）保存後にfinish。

事前アンケートはphase=presurvey、事後アンケートはphase=posttestで別々に記録する。事前はモード別の版付きで経験・条件付き理解度・AI利用回答を保存する。現行事後v4はシステム評価1項目・教材評価6項目（閲覧者のみ必須）・任意自由記述とし、H4は教材評価6項目を個別に参照する。仕様版52のv3/v4回答は各protocol当時の内容で保全する。[画面仕様](09_frontend_ux_flow.md)、[評価定義](12_evaluation_metrics.md)、[保存契約](49_presurvey_baseline.md)を参照する。

事前後の問題variantは採点回次に対応して全用語共通に選ぶ。用語別の回答件数から回次を推測しない。学習後回数retest_cycles_completedはfinal_testを含めず、上限用のpost_pretest_tests_completedには採点済みfinal_testを加える。テスト回答中はチャット・ヒント・即時正解を表示しない。既存結果画面では従来どおり正誤を表示する。

学習ギブアップはretestへ進む。retest/final_testの実験ギブアップはsurveyへ進む。採点・ギブアップ・再送・先行生成は仕様版の確認後に実行する。学習確認の出題規則は両群共通で、unknownはenrichment、M1/M3はconceptual_change。同じ状態・回答・ターンなら同じ問題とvariantを使う。

仕様版42採用時には、仕様版41以下、旧protocol_id、NULL・未対応版の記録を閲覧専用で保全していた。新規開始は同意を取り直して新しいIDを作成した。当時の参加者には仕様版42を保存し、教材内解説では辞書v4を意味参照として生成入力に含め、本文では逐語転載せず文脈に合わせて言い換えた。本文は800文字程度を目安にし、文字数の上下限による合否判定や長さだけを理由にした再生成を行わなかった。教材の右側注釈欄は表示せず、統制群には群別の自然言語方略指示を送らず、提案群だけに診断・教授指示を追加した。旧版の保存済み教材・注釈snapshot・監査記録は変更しない。[事前アンケート](49_presurvey_baseline.md)、[教材モード](41_learning_glossary_material_mode.md)、[文字数目標](42_learning_glossary_material_length.md)、[辞書と言い換え](43_glossary_definition_paraphrase.md)、[PRETEST履歴](44_pretest_content_revision.md)、[RAG注釈](49_rag_glossary.md)。通常版ペア確認の契約は[40](40_question_pair_answer_review.md)に記録する。
