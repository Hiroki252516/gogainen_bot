# 行動選択型テスト問題と分類根拠

## 適用範囲

実験仕様版12 / `experiment-plan-2026-10-25-learning-confirmation-v1`。通常版問題バンク識別子は `scenario-actions-v4`。3用語×3回次＝9固有問題で、各回に3問を出題する。内部final_testは事前後1回目のretest_v1を共用し、その後はretest_v2へ進む。両経路とも事前テストを含め最大3回である。

LLM知識の3問は、承認された製品サポート・問い合わせ分類・議事録作成の3案を基にする。版9で通常版事前の問1 C/I、問2 D、問3 A/D/Iと対応する誤答4選択肢の教授対象を改訂した。場面・設問・その他の選択肢・再テストは変更しない。変更前のscenario-actions-v1は[アーカイブ](../backend/app/seed/content/archive/learning_content_scenario_actions_v1.yml)へ保全する。

版10では問1のA・Bだけを下記の文章へ変更した。どちらも正解のままで、訂正情報やその他の本文は変えない。版9で使用したscenario-actions-v2は[アーカイブ](../backend/app/seed/content/archive/learning_content_scenario_actions_v2.yml)に保存し、DBでも旧問題・選択肢IDを保持する。

版11では問1のFだけを下記の指定文へ変更した。M1判定と訂正情報は維持する。版10で使用したscenario-actions-v3は[アーカイブ](../backend/app/seed/content/archive/learning_content_scenario_actions_v3.yml)に保存し、旧ID・本文・回答・snapshotを書き換えない。

通常版・易しい版の全テスト・学習確認から選択肢の数値的な文長検査を撤廃した。非空・重複・選択肢数・役割数・教授対象の検査は維持する。文長の均一性は保証しないため、長さが回答の手掛かりとなる可能性も予備調査で確認する。教材600〜800文字条件は変えない。

## 判定の位置づけ

以下は研究者が問題設計のために定めた操作的分類であり、選択から本人の確定した信念を断定しない。M3候補は機能・データ・主体・工程などの取り違えを表すよう設計しているが、Chiのカテゴリー転換と同等であることや、M1との弁別妥当性を実証したものではない。3形式の難易度・平行性も未検証であり、収集前に指導教員の確認・試行が必要である。

同じモデルを複数のエージェントとして用いることは可能であり、モデル数だけでマルチエージェントを判定しない。またRAGは記憶の検索にも利用でき、両者を排他的な方式とは扱わない。一時的な会話文の入力も、保存済み履歴の再利用であれば記憶利用の一部になり得る。誤答では「それだけで必要な管理機構まで実装できる」とする飛躍を対象とする。

表のラベルはcanonicalなデバッグ配置であり、ランダム配置時の表示位置とは異なる。正解3・M1誤答3・M3誤答3・J「わからない」の構成とM3優先判定を維持する。

## 旧問題と教授対象

旧問題の原文・教授対象は [archive/learning_content_pre_issue156.yml](../backend/app/seed/content/archive/learning_content_pre_issue156.yml) に変更前のまま保存した。retest_v3もこのアーカイブに含み、通常出題しない。さらに古いretest_v4/v5・独立final_test_v1・旧学習v2は[archive/learning_questions_v2_unused.yml](../backend/app/seed/content/archive/learning_questions_v2_unused.yml)に保持する。

現行の訂正・仕組み・対比例・M3の境界は [standard/learning_content.yml](../backend/app/seed/content/standard/learning_content.yml) のteaching_targetsを参照する。新しい事前選択肢のD〜Iに対応し、LLM知識Hは訓練と検索、Iは入力と保存機構を対象とする。旧問題の選択肢IDと本文は別DBレコードとして保持し、旧回答やsnapshotを書き換えない。
