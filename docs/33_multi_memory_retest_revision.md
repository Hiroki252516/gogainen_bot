## 記憶プロセス / retest_v2

企業が、利用者からの問い合わせに対応するAIを開発している。ある利用者は以前の相談で「今後の連絡は電話でしてほしい」と伝えたが、別の日に「これからはメールで連絡してほしい」と希望を変更した。

さらに、案内メールを受け取った際に、「文章が長いとわかりにくいので、次からは要点を先に書いてほしい」と感想を伝えた。

開発担当者は、利用者が別の日に新しい問い合わせをした場合にも、その利用者の現在の連絡方法や案内文への希望を反映できる記憶機能を設けたいと考えている。

## 分類と解釈の留意点

M1は共有・照合・更新・保存の成立条件や効果についての誤った主張、M3は回答の見出し・処理分岐・検索ツール・訓練・入力操作・個人の記録を異なる種類の機構と取り違える主張として、研究上の操作的分類を割り当てる。

マルチエージェントV1のEは他担当の結果を引き継ぐこと自体を誤りとせず、人気順を移動条件に応じて見直す必要があっても優先するという制約を対象とする。ツールを使うエージェントやツールを内部に持つ複合構成一般を否定せず、時刻や展示情報を返すだけの機能を、それ自体で判断する独立したAIエージェントとして数える点を対象とする。

記憶問題は会話の全文保存、追加訓練、公開レシピ・類似事例の検索、過去会話の再入力を一律に誤りとしない。それだけで本人の希望を継続的に保存・取得・変更管理できるとする部分、別の人の事例を今回の本人の記憶とみなす部分を対象とする。古い会話そのものの削除を必須とせず、現在有効な希望を区別して更新する意味で扱う。

Chiの理論がこの36選択肢の割当を直接実証したわけではない。機械検査・MockだけでM1/M3の弁別妥当性、難易度同等性、初心者への読みやすさを実証したとは扱わず、内容確認・予備調査を別途行う。選択肢の数値的な文長検査は撤廃済みで、文長の均一性や長さが手掛かりにならないことも保証しない。
