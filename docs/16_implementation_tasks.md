# 現行実装の責務

1. 実験仕様版と旧試用の読み取り専用境界。
2. 固定複数選択、M1/M3/unknown分類、既存採点・遷移。
3. backend方略決定とAIの3生成タスク。
4. 実送信監査、AI生成の章立てと節本文証拠、必須教授/安全性/文字数/方略検証。固定見出しによる自動証拠補正はしない。
5. 共通RAGと全フェーズの共通回答履歴、実験群だけの診断・誤概念教授入力、診断連動の両群共通出題。
6. 先行生成、冪等性、現行評価と履歴/CSVの分離。
7. 結果確認と管理者の旧試用表示。

旧分類・支援量・追加評価・自由回答を再導入しない。正解位置の分散復旧は別作業。コミット/pushは明示指示まで行わない。
