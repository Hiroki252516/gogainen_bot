# 03. Misconception Taxonomy

本システムでは、最終分類としてM1〜M4を採用する。過去案にあった「日常語混同」「定義暗記型」「適用条件誤解型」などは、最終的には以下の4分類へ統合する。

## M1: カテゴリー誤分類型

### 定義

対象概念が何の種類のものかを取り違えている状態。

### 例

- Embedding = データの保存場所
- Attention = 人間の注意や集中
- Loss = AIが失敗して自信を失う状態
- Prompt = AIの内部にある考える力

### 診断基準

学習者の回答が、概念を以下のような本来とは異なるカテゴリーに置いている。

- 物理的な場所
- 人間の心理状態
- AIの人格・気分
- 単なる保存
- 単なる知識そのもの

### 教授方略

カテゴリー再定位型説明。

- 「何ではないか」を明確にする
- 「何の種類の概念か」を言い直す
- 誤カテゴリーと正カテゴリーを比較する

## M2: 類似概念境界混同型

### 定義

似ている概念の違いが分かっていない状態。

### 例

- Attention と Embedding の混同
- 過学習 と 汎化 の混同
- Fine-tuning と Prompt engineering の混同
- RAG と Fine-tuning の混同
- Loss と Accuracy の混同
- 正則化 と 正規化 の混同

### 診断基準

学習者が関連する別概念の説明をしている。または2概念を「同じもの」と扱っている。

### 教授方略

境界比較型説明。

- 2概念の比較表
- 役割の違い
- 入力・処理・出力の違い
- 使う場面の違い

## M3: 表層特徴・キーワード反応型

### 定義

問題文の目立つ単語・数値・記号などに反応し、原理や構造に基づかずに答えている状態。

### 例

- 「訓練」と書いてあるから過学習
- Attention = 重要な単語を探す処理
- Loss = お金やデータが失われる量
- Fine = きれいにするという意味だから文章を整える
- 正則化 = 「正」という字があるから出力を正しくする

### 診断基準

回答理由が、概念の仕組みではなく、表面的な語感・単語・漢字・英単語の直訳に依存している。

### 教授方略

深層構造注目型説明。

- キーワードではなく判断基準を示す
- 表層的判断がなぜ危険かを示す
- 原理・構造・関係性を説明させる

## M4: 文脈転移失敗型

### 定義

特定の文脈では説明できるが、文脈が変わると概念を適用できない状態。

### 例

- 画像分類では過学習が分かるが、チャットボットの言い換え質問では分からない
- Promptを質問文としては分かるが、命令文や制約文を含む入力では判断できない
- RAGを検索付きQAでは分かるが、社内文書参照の業務支援では説明できない

### 診断基準

基本問題・同型問題では正答しているが、転移問題で誤答する。あるいは学習時と異なる文脈で、同じ判断基準を使えない。

### 教授方略

文脈変換型練習。

- 学習時の文脈と転移先の文脈を比較する
- 共通構造を抽出する
- 別文脈で同じ概念を使わせる

## Unknown: 知識不足

「わからない」選択肢、空欄、または概念に関係する記述がほぼない場合。誤概念ではなく、基礎知識不足として扱う。

## Ambiguous: 判定不能

選択肢と理由記述が矛盾する、またはAI診断の信頼度が低い場合。管理画面で要確認として表示する。
