# 03. Misconception Taxonomy

本システムでは、最終分類としてM1〜M4を採用する。過去案にあった「日常語混同」「因果誤認」「定義暗記型」「適用条件誤解型」「表層キーワード依存型」などは、最終的には以下の4分類へ統合する。

## 分類の使い方

- M1〜M4は内部分析ラベルである
- 通常の学習セッション画面ではデバッグ欄にMラベルを表示する。教材本文、問題文、フィードバック本文にはMラベルを直接書かない
- 管理画面、CSV、AIログには保存する
- 統制群でも分析用に分類してよいが、教授方略には使わない
- M4は再テストや確認テストの記述内容から、文脈適用の失敗が明確な場合に内部判定する

## M1: カテゴリー誤分類型

### 定義

対象概念が何の種類のものかを取り違えている状態。

### 例

- 転移学習 = 学習データを別の保存場所へ移動する作業
- Transformer = AIが文章全体を人間のように意識して読む能力
- Attention = 人間の注意や集中
- LLMの学習段階 = 入力、思考、感情、会話という人間の学習段階
- 事前学習 = 利用前にAIへ注意書きを与えること
- 事後学習 = AIが回答後に反省して感情を整える段階

### 診断基準

学習者の回答が、概念を以下のような本来とは異なるカテゴリーに置いている。

- 物理的な場所
- 人間の心理状態
- AIの人格・気分
- 単なる保存
- 単なる知識そのもの
- 社会的な正しさや常識

### 教授方略

カテゴリー再定位型説明。

- 「何ではないか」を明確にする
- 「何の種類の概念か」を言い直す
- 誤カテゴリーと正カテゴリーを比較する
- 正しい上位カテゴリーを先に置いてから具体例に進む

## M2: 類似概念境界混同型

### 定義

似ている概念の違いが分かっていない状態。

### 例

- 転移学習 と事前学習の混同
- Transformer とRNNの混同
- Attention とFFNの混同
- 事前学習 とインストラクションチューニングの混同
- 事前学習 と事後学習の混同
- LLMの学習段階 とプロンプト機能の混同

### 診断基準

学習者が関連する別概念の説明をしている。または2概念を「同じもの」と扱っている。

判定の典型:

- Aを説明すべき問題でBの定義を書いている
- 「どちらも同じ」「似たもの」として境界を説明できない
- 入力、処理、出力、更新対象の違いを取り違えている

### 教授方略

境界比較型説明。

- 2概念の比較表
- 役割の違い
- 入力、処理、出力の違い
- 使う場面の違い
- 「この場合はどちらか」を判断する短問

## M3: 表層特徴・キーワード反応型

### 定義

問題文の目立つ単語、数値、記号、漢字、英単語の直訳などに反応し、原理や構造に基づかずに答えている状態。

### 例

- 転移学習 = transferという語から翻訳やファイル転送だけを指す
- Transformer = 名前に「変換」とあるため翻訳機能だけを指す
- Attention = 重要そうな単語だけを探して印を付ける処理
- 事前学習 = 「事前」なのでユーザが入力する前置きのこと
- 事後学習 = 「事後」なので回答後にログを保存すること
- LLMの学習段階 = 事前テストと事後テストだけを指す

### 診断基準

回答理由が、概念の仕組みではなく、表面的な語感・単語・漢字・英単語の直訳に依存している。

判定の典型:

- 理由が「この単語があるから」だけで終わる
- 指標や文脈の関係を説明していない
- 正答選択肢に近い語を選んだだけで理由が不十分

### 教授方略

深層構造注目型説明。

- キーワードではなく判断基準を示す
- 表層的判断がなぜ危険かを示す
- 原理、構造、関係性を説明させる
- 似た表層語を含む反例を出す

## M4: 文脈転移失敗型

### 定義

特定の文脈では説明できるが、文脈が変わると概念を適用できない状態。

### 例

- 転移学習を定義では説明できるが、少量の専門分野データへ学習済みモデルを適用する場面で使えない
- Transformerを定義では説明できるが、長文要約で離れた語の関係を扱う場面に適用できない
- Attentionを文章処理では説明できるが、質問応答で質問文と本文の関連箇所を結びつける場面に適用できない
- 事前学習を定義では説明できるが、大量テキストから次単語予測を行う訓練場面に適用できない
- 事後学習を定義では説明できるが、有害出力を抑える調整場面に適用できない

### 診断基準

基本問題・同型問題では正答しているが、転移問題で誤答する。あるいは学習時と異なる文脈で、同じ判断基準を使えない。

M4は独立した転移テストでは扱わない。再テストや確認テストの記述内容から文脈適用の失敗が明確な場合に内部判定する。

### 教授方略

文脈変換型練習。

- 学習時の文脈と転移先の文脈を比較する
- 共通構造を抽出する
- 別文脈で同じ概念を使わせる
- 「表面は違うが同じ判断基準」を言語化させる

## Unknown: 知識不足

「わからない」選択肢、または記述式テストで概念に関係する記述がほぼない場合。誤概念ではなく、基礎知識不足として扱う。事前テストでは理由記述を収集しないため、選択肢だけで判定する。

Unknownは同種誤答再発率の分子・分母には含めない。ただし、知識不足の継続として別集計できるように保存する。

## Ambiguous: 判定不能

記述式テストで選択肢と理由記述が矛盾する、またはAI診断の信頼度が低い場合。管理画面で要確認として表示する。事前テストでは理由記述を収集しない。

例:

- 正答選択肢を選んだが理由が明らかにM2
- 誤答選択肢を選んだが理由は正しい
- 複数の誤概念が同程度に含まれる

Ambiguousは自動評価から除外するのではなく、`diagnosis_confidence` と `requires_manual_review` を保存する。

## 旧分類から最終分類への対応

5月18日案ではM1〜M6の分類が使われていた。5月25日案では先行研究との対応を整理し、現在のM1〜M4へ統合する。

| 旧分類 | 最終分類 | 理由 |
|---|---|---|
| 日常語混同型 | M1 カテゴリー誤分類型 または M3 表層特徴型 | 日常語の意味へ置き換える場合はM1、単語の表面だけで判断する場合はM3 |
| 類似概念混同型 | M2 類似概念境界混同型 | 近接概念の境界が曖昧なため |
| 因果誤認型 | M2 または M3 | 別概念との関係誤りならM2、表層的な因果語への反応ならM3 |
| 定義暗記型 | M4 文脈転移失敗型 | 定義は言えるが事例へ適用できないため |
| 適用条件誤解型 | M4 文脈転移失敗型 | 文脈や条件が変わると使えないため |
| 表層キーワード依存型 | M3 表層特徴・キーワード反応型 | 表面特徴に基づく判断のため |

## 診断優先順位

1. 「わからない」または空欄なら `unknown`
2. 選択肢に内部ラベルがある場合は初期ラベルとして採用
3. 事前テストでは理由記述を使わず、選択肢ラベルだけで診断する
4. 再テスト、確認テストでは理由記述が初期ラベルと矛盾する場合にAI診断で上書き候補を出す
5. 再テストや確認テストで文脈適用の失敗が明確な場合はM4
6. 信頼度が低い場合は `ambiguous` として手動確認対象

## 用語別の代表誤概念

現行MVPで扱う用語は以下の2語である。その他の用語は過去仕様・拡張候補として扱う。

| 用語 | M1 | M2 | M3 | M4 |
|---|---|---|---|---|
| 転移学習 | 学習データを別の保存場所へ移動する作業 | 事前学習と同じくゼロから基盤モデルを作ること | transferの語感から翻訳やファイル転送だけを指す | 少量データの別タスクへ学習済みモデルを適用できない |
| LLMの学習段階 | 人間の学習段階 | プロンプトやFunction Callingと同じ | 事前/事後テストだけを指す | 新しいLLM作成の工程説明に適用できない |

過去仕様・拡張候補:

| 用語 | M1 | M2 | M3 | M4 |
|---|---|---|---|---|
| Transformer | 人間のように文章全体を意識する能力 | RNNと同じ逐次処理 | 翻訳機能だけを指す | 長文要約など離れた語の関係処理に適用できない |
| Attention | 人間の注意 | FFNと同じ | 重要語を探すだけ | 質問応答で関連箇所を結びつける場面に適用できない |
| 事前学習 | 利用前の注意書き | インストラクションチューニングと同じ | 「事前」の語感だけで判断 | 次単語予測など大量データ訓練に適用できない |
| 事後学習 | 回答後の反省 | 事前学習と同じ | ログ保存だけを指す | 有害出力抑制や有用性調整に適用できない |
