# 03. Misconception Taxonomy

現行実装では、誤概念タイプをM1〜M4の内部ラベルとして保存する。被験者向け画面の教材本文やフィードバック本文には、M1〜M4を直接表示しない。管理画面のデバッグ・調査用ログには表示してよい。

## Final Labels

| Label | 名称 | 判定の意味 |
|---|---|---|
| M1 | カテゴリー誤分類型 | 概念を本来とは異なる種類のものとして捉える |
| M2 | 類似概念境界混同型 | 似た概念との違いや境界を区別できない |
| M3 | 表層特徴・キーワード反応型 | 語感、名前、表面的な単語へ反応している |
| M4 | 文脈転移失敗型 | 基本文脈では説明できても別文脈で使えない |
| unknown | 不明・未回答 | 「わからない」または分類不能 |

## LLMの学習段階

| Label | 典型例 |
|---|---|
| M1 | 事前学習やチューニングを、人間の理解・思考・意図形成のような認知過程として捉える |
| M2 | プロンプト、コンテキストウィンドウ、Function Callingなど推論時の仕組みと学習段階を混同する |
| M3 | 「事前」「事後」という語から、学習前後のテストや評価手順だけを指すと考える |
| M4 | 3段階の名前は言えるが、新しいLLMを作る説明資料で各段階の役割を対応づけられない |

## Transformer

| Label | 典型例 |
|---|---|
| M1 | Attentionを人間の意識や集中力、FFNを思考や判断として捉える |
| M2 | TransformerをRNNのような逐次処理構造として捉える |
| M3 | Attentionを単語検索、FFNを単語置換、Transformerを翻訳機能だけとして捉える |
| M4 | Attention/FFNの説明はできるが、長文要約など離れた語同士の関係を扱う場面に適用できない |

## 保存と利用

- `attempts.misconception_type` はテスト回答の主分類を保存する
- `tutor_turns.grading_json.learning_misconception_type` は学習ターン内の回答判定を保存する
- 提案群では、誤概念タイプ、過去ログ、学習ステージを教授方略に使う
- 統制群では、誤概念タイプを保存しても教授方略には使わない
- 同じ用語で同じ誤概念タイプが再テストなどで再発した場合、`recurrence_events` と `attempts.recurrence_flag` に記録する

## 調査ログ

管理画面とCSVでは、テスト回答と学習ターン回答を `answer_history` として統合して確認する。テスト回答は `source_type=test_attempt`、学習ターン回答は `source_type=learning_turn` として区別する。
