# 誤概念分類

今回のMVPでは、Transformer問題に対して M1、M3、unknown のみを扱う。被験者向け画面の教材本文やフィードバック本文には、M1/M3 などの内部ラベルを直接表示しない。管理画面・研究ログでは表示してよい。

| ラベル | 名称 | 定義 |
| --- | --- | --- |
| M1 | 誤信念型 | TransformerやAttention/FFNを、人間のような意味理解・思考・判断を行う仕組みとして捉える誤り |
| M3 | カテゴリー錯誤型 | Transformerをモデルアーキテクチャではなく、アプリ、機能、知能主体など本来と異なるカテゴリーで捉える誤り |
| unknown | 知識不足 | 「わからない」を選ぶ、または判断に必要な基本知識が不足している状態 |

M2とM4はDB互換値として残してよいが、今回のMVPのseed、判定、画面、研究ログの主導線では新規生成しない。

## Transformerの判定

正解は A/B/C の3つだけを選択した場合である。

| 選択肢 | 判定 |
| --- | --- |
| A, B, C | 正解 |
| D, E, F | M1 |
| G, H, I | M3 |
| J | unknown |

複数選択の不正解分類は、選択肢にM3が含まれればM3を優先する。M3がなくM1が含まれればM1とする。Jのみならunknownとする。

スライド37由来の古い「D〜J単独」「K/L」「M2候補」判定ルールは今回の仕様に含めない。
