# 03. Misconception Taxonomy

本システムでは、最終分類としてM1〜M4を採用する。現行選択式フローでは、M1〜M3とunknownを固定選択肢メタデータから確定し、M4は将来の転移テスト用に保持する。

## 分類の使い方

- M1〜M4は内部分析ラベルである
- 被験者画面にMラベルを直接表示しない
- 管理画面、CSV、AIログには保存する
- 学習中は両群とも選択肢メタデータとしてMタイプを保存する
- 統制群では保存したMタイプを後続教材の個別化に使わない
- 提案群のAI呼び出しには、実行時payloadとして `misconception_taxonomy` と `teaching_guidelines` を渡す
- 統制群のAI呼び出しには、taxonomy、初期診断、再テスト診断、学習履歴を渡さない
- M4は将来の転移テスト拡張用に保持する。現行参加者フローでは転移テストを実施しないため、主評価には含めない

## M1: カテゴリー誤分類型

### 本質的定義

対象概念が「何の種類のものか」を取り違えている状態。抽象的な処理、表現、評価指標、学習方法などを、本来とは異なる上位カテゴリー、たとえば物理的な場所、人間の心理、AIの人格、単なる保存場所、社会的な正しさとして扱っている。

### 例

- Embedding = データの保存場所
- Attention = 人間の注意や集中
- Loss = AIが失敗して自信を失う状態
- Prompt = AIの内部にある考える力
- RAG = AIの中に巨大な図書館が物理的に入っている状態

### 診断基準

学習者の回答が、概念を本来とは異なるカテゴリーに置いている場合にM1とする。

- 物理的な場所
- 人間の心理状態
- AIの人格・気分
- 単なる保存
- 単なる知識そのもの
- 社会的な正しさや常識

### 教材生成指針

カテゴリー再定位型説明を使う。

- 「何ではないか」を明確にする
- 「何の種類の概念か」を言い直す
- 誤カテゴリーと正カテゴリーを比較する
- 正しい上位カテゴリーを先に置いてから具体例に進む

### 避ける支援

- 誤ったカテゴリーを残したまま細部の知識だけを足さない
- AIの気持ち、意思、人格のような擬人化で説明しない
- 比喩を使う場合も、正しいカテゴリーに戻す文を必ず入れる

### 研究根拠

Chiの概念変化研究では、誤った知識は単なる知識不足ではなく、既有知識が学習対象と衝突する状態として扱われる。特にカテゴリー誤りは、同じ階層内の細部修正ではなく、概念を置くカテゴリーの転換が必要になる。M1はこのカテゴリー転換を必要とする誤概念として定義する。

## M2: 類似概念境界混同型

### 本質的定義

対象概念に近い別概念の意味はある程度持っているが、両者の境界を区別できていない状態。対象概念を説明すべき場面で、関連する別概念の定義、役割、入力、処理、出力、使う場面を答えてしまう。

### 例

- Attention と Embedding の混同
- Token と Embedding の混同
- 過学習 と 汎化 の混同
- Fine-tuning と Prompt engineering の混同
- RAG と Fine-tuning の混同
- Loss と Accuracy の混同
- 正則化 と 正規化 の混同

### 診断基準

学習者が関連する別概念の説明をしている、または2概念を「同じもの」「似たもの」として扱い、境界を説明できない場合にM2とする。

判定の典型:

- Aを説明すべき問題でBの定義を書いている
- 「どちらも同じ」「似たもの」として境界を説明できない
- 入力、処理、出力、更新対象の違いを取り違えている

### 教材生成指針

境界比較型説明を使う。

- 2概念の役割の違い
- 入力、処理、出力、更新対象の違い
- 使う場面の違い
- 同じ文脈で片方だけが当てはまる例
- 「この場合はどちらか」を判断する短問

### 避ける支援

- 2概念を別々に説明するだけで終えない
- 「似ている」とだけ言って、境界を曖昧に残さない
- 比較対象を増やしすぎて、混同しているペアの違いをぼかさない

### 研究根拠

Hassani, Ghodsi, and Howellは、標準偏差と標準誤差という近接した統計概念を学生が混同しやすいことを扱っている。この論文はM2の広い理論全体ではなく、類似概念の境界混同が学習上の問題になる具体例として参照する。教授方略としては、関連概念を対比して相違点に気づかせるcontrasting casesや比較学習の知見も補助根拠とする。

## M3: 表層特徴・キーワード反応型

### 本質的定義

問題文や選択肢の目立つ単語、数値、記号、漢字、英単語の直訳、語感、名称の印象に反応し、概念の原理、構造、関係、判断条件に基づかずに答えている状態。

### 例

- 「訓練」と書いてあるから過学習
- Attention = 重要な単語を探す処理
- Loss = お金やデータが失われる量
- Fine = きれいにするという意味だから文章を整える
- 正則化 = 「正」という字があるから出力を正しくする
- Prompt = 質問文と書いてある場合だけ該当する

### 診断基準

回答理由が、概念の仕組みではなく、表面的な語感、単語、漢字、英単語の直訳、名称の印象に依存している場合にM3とする。

判定の典型:

- 理由が「この単語があるから」だけで終わる
- 指標や文脈の関係を説明していない
- 正答選択肢に近い語を選んだだけで理由が不十分

### 教材生成指針

深層構造注目型説明を使う。

- キーワードではなく判断基準を示す
- 表層的判断がなぜ危険かを示す
- 原理、構造、関係性を説明させる
- 似た表層語を含む反例を出す

### 避ける支援

- キーワード暗記を正しい解き方として強化しない
- 英単語の直訳や漢字の印象だけで説明しない
- 表面上似た言い換えだけを増やして、判断基準を示さないままにしない

### 研究根拠

Chi, Feltovich, and Glaserの専門家・初心者比較では、初心者は問題の文字通りの表層特徴に基づいて表象しやすく、専門家は背後の原理に基づいて表象することが示されている。M3は、AI・情報系概念でも同様に、表層語ではなく深層構造や判断基準へ注意を向け直す必要がある誤概念として定義する。

## M4: 文脈転移失敗型

### 定義

特定の文脈では説明できるが、文脈が変わると概念を適用できない状態。

### 例

- 画像分類では過学習が分かるが、チャットボットの言い換え質問では分からない
- Promptを質問文としては分かるが、命令文や制約文を含む入力では判断できない
- RAGを検索付きQAでは分かるが、社内文書参照の業務支援では説明できない
- Attentionを文章処理では説明できるが、画像説明モデルの領域重み付けに適用できない

### 診断基準

基本問題・同型問題では正答しているが、別文脈で同じ判断基準を使えない状態を指す。

現行MVPでは転移テストを実施しないため、M4は旧互換・将来拡張用の分類として保持する。初期テスト、再テスト、最終テストの選択肢ラベルにはM4を置かない。

### 教授方略

文脈変換型練習。

- 学習時の文脈と転移先の文脈を比較する
- 共通構造を抽出する
- 別文脈で同じ概念を使わせる
- 「表面は違うが同じ判断基準」を言語化させる

## Unknown: 知識不足

「わからない」選択肢、空欄、または概念に関係する記述がほぼない場合。誤概念ではなく、基礎知識不足として扱う。

Unknownは同種誤答再発率の分子・分母には含めない。ただし、知識不足の継続として別集計できるように保存する。

## Resolved: 現在の固定問題で正答

学習中の選択問題へ正答した状態。自力正答と3回誤答後の `forced_resolved` は区別して保存する。

- `provisional`: 1回のpass
- `confirmed_in_learning`: 次フェーズでもpass
- `confirmed_by_retest`: 再テストでも正答

## Ambiguous

現行学習問題では使用しない。旧自由記述データとの互換のため列と値だけを保持する。

## 旧分類から最終分類への対応

5月18日案ではM1〜M6の分類が使われていた。5月25日案では先行研究との対応を整理し、現在のM1〜M4へ統合する。

| 旧分類 | 最終分類 | 理由 |
|---|---|---|
| 日常語混同型 | M1 カテゴリー誤分類型 または M3 表層特徴型 | 日常語の意味へ置き換える場合はM1、単語の表面だけで判断する場合はM3 |
| 類似概念混同型 | M2 類似概念境界混同型 | 近接概念の境界が曖昧なため |
| 因果誤認型 | M2 または M3 | 別概念との関係誤りならM2、表層的な因果語への反応ならM3 |
| 定義暗記型 | M4 文脈転移失敗型 | 定義は言えるが事例へ適用できないため |
| 適用条件誤解型 | M4 文脈転移失敗型 | 文脈や条件が変わると使えないため |
| 表層キーワード依存型 | M3 表層特徴・キーワード反応型 | 表面特徴に基づく判断のため |

## 診断優先順位

1. correctなら `resolved`, misconception_type=null
2. M1/M2/M3なら `misconception`
3. unknownなら `unknown`
4. AIは学習中の分類を上書きしない

## 用語別の代表誤概念

| 用語 | M1 | M2 | M3 | M4 |
|---|---|---|---|---|
| Attention | 人間の注意 | Embeddingと同じ | 重要語を探すだけ | 画像領域や音声文脈に適用できない |
| Embedding | 知識の保存場所 | AttentionやTokenと同じ | 埋め込みという語感だけで判断 | 文・画像・ユーザーなど異なる対象の表現に適用できない |
| Token | 意味そのもの | Embeddingと同じ | 短い記号だけ | 日本語分割やサブワード文脈で説明できない |
| 過学習 | 勉強しすぎて疲れる | 汎化と同じ | 訓練という語だけで判断 | チャットボットや推薦など別文脈で説明できない |
| 汎化 | 一般常識を理解 | 過学習と同じ | 細部を無視する | 未知質問や新規データ文脈で説明できない |
| Fine-tuning | AIの性格調整 | Prompt engineeringと同じ | fineの語感で判断 | ドメイン適応や分類器調整へ適用できない |
| Prompt | AI内部の思考力 | 学習データやFine-tuningと同じ | 質問文だけ | 命令、制約、例示を含む入力に適用できない |
| RAG | AI内の物理的図書館 | Fine-tuningと同じ | 検索結果コピー | 社内文書、FAQ、法務文書などへ適用できない |
