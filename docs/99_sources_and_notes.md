# 根拠と設計履歴

現行仕様版2は3概念、M1/M3/unknown、固定複数選択、結果の正誤表示、既存の学習/再テスト遷移を基準とする。現在の3仮説はdocs/01_research_requirements.mdを参照する。統計手法・評価式・問題本文/位置を今回再設計しない。

Issue #138では、両群で同じ用語の全フェーズの採点済み回答履歴を共有し、proposedだけに明示的な診断・対象主張・taxonomy・教授方針を追加する。確認問題は既存proposedの診断連動規則を両群で使う。統制群の自然な誤り訂正は許容し、比較を「誤概念対応全般の有無」ではなく「明示的な構造化対応の追加効果」と位置づける。実験群の教授契約・検証はこの追加介入の一部である。

研究計画PPTX、論文、旧案の根拠と引用元は [更新前の資料](history/2026-10-06/99_sources_and_notes.md) に保存した。歴史的資料であり、旧実行経路を戻す要件ではない。

- 全既存試用を閲覧専用とし、削除や現行版への一括付け替えをしない。
- 教材内transfer_checkは維持し、独立した追加テストと区別する。
- stable_correct_countは正答記録として維持する。
- 旧物理列/値は保持するが教授・採点・評価で旧支援量/旧成功判定を使わない。
- 一時デバッグ配置は維持し、収集前に別作業で分散を復旧する。

旧文書はhistory/2026-10-06。現行実装と仕様版2の文書を優先する。別のai_tutor_codex_specリポジトリはこの変更の対象外。
