# AI Prompt Contracts

## 共通契約

AI教材生成は `AIBackend` 経由で行い、実行時の教材根拠としてローカルRAG本文を使う。RAG検索クエリは対象用語、学習段階、構成要素だけで組み立て、個人の誤答履歴によって検索対象の章を変えない。

両群へ渡す共通payload:

- term slug / 表示名
- learning stage
- 構成要素
- YAMLで固定した確認問題・選択肢
- 用語に対応するRAG本文と対象section

proposedだけへ追加する情報:

- learner state / scaffolding level
- 過去の回答・学習ターン履歴
- 誤概念タイプと診断理由
- `misconception_taxonomy` のM1〜M4/unknown定義

control payloadには `misconception_taxonomy`、誤概念履歴、学習者履歴を含めない。controlの `teaching_strategy` は `general_explanation` に固定する。

## 内部taxonomy

- M1（誤信念型）: 単一の命題・信念が誤っており、明示的または暗黙的反証による置き換えが必要。
- M2（欠陥メンタルモデル型）: 複数の信念がつながった説明モデル全体が不整合であり、中核前提の複数修正とモデル再構成が必要。
- M3（カテゴリー誤り型）: 概念を誤った上位カテゴリーに分類しており、正しいカテゴリーの特徴・境界を示して再配置する必要がある。
- M4（欠如したスキーマ型）: 必要なカテゴリーや関係の知識構造が不足しており、新しいスキーマの構築が必要。
- unknown: 誤概念と断定せず、基礎知識・用語・具体例の補充を優先する。

AIには、上記の定義に沿った教材方略だけを内部指示する。被験者向け本文にMラベルや研究者向け分類名を出力しない。

## 出力方針

- M1: 誤った信念と正しい信念を短く対比し、反証と置き換えを促す。
- M2: 複数の誤った前提を分解し、中核関係を順に再構成する。
- M3: 「何の種類か」「何ではないか」を示し、正しいカテゴリーへ再分類する。
- M4: 不足する概念・関係・適用場面を具体例とともに補い、スキーマを構築する。
- unknown: 最小限の前提説明、構成要素、具体例を優先する。

教材本文は次のMarkdown構成を必須とする。

```markdown
## 用語名

### 要点
- 中心となる定義や役割

### 具体例
- 判断基準が分かる短い例

### 注意点
- よくある混同や誤解
```

必要な場合だけ「前提用語とのつながり」「何ではないか」を追加する。教材と学習者向けフィードバックは、見出し、箇条書き、太字、短い段落を中心にする。表、HTML、コードブロック、画像、長大な連続段落、内部ラベルの露出は禁止する。既存JSON schema、DB列、CSV列は変更しない。

backendは構造化JSONの形と必須フィールドを検証するが、Markdownの見出し構成を完全な文法検証器として検証しているわけではない。frontendの `MarkdownText` がraw HTML、表、画像、コードブロックを描画しない安全表示を担当する。既存のプレーンテキストは通常の段落として表示する。

## 回答後解説

確認問題の正誤は、AIの判定ではなく、固定YAMLの選択肢とbackendの採点ロジックを唯一の正本とする。採点結果を確定した後、DBの回答状態を更新する前に、結果に応じて解説専用のAI呼び出しを行う。

- 正答時は `generate_correct_answer_summary` を呼び、`{"summary": "..."}` を受け取る。
- 誤答時は `explain_selected_distractor` を呼び、`{"feedback": "...", "remediation_focus": "...", "general_knowledge_supplement": null}` を受け取る。
- どちらの呼び出しも既存の `_ai_call` 経由で行い、目的、payload、応答、遅延を `AICallLog` に記録する。
- proposedには誤概念taxonomy、今回の誤概念タイプ、学習履歴、足場掛け情報を追加する。controlには用語、学習段階、問題、教材、RAG本文、選択内容だけを渡し、taxonomy・誤概念履歴・学習者履歴を渡さない。
- 誤答解説は、選択された誤答の問題点と見直す観点だけを示し、正答の本文、正答位置、正答そのものを直接漏洩しない。
- 解説本文は教材と同じ安全なMarkdown制約に従う。HTML、表、コードブロック、画像、長大な連続段落、M1〜M4、AIの思考過程を出力しない。
- 解説生成に失敗した場合はMockへ自動フォールバックせず、回答状態を中途半端に確定せずにAIエラーとして扱う。
