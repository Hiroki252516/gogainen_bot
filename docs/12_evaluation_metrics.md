# 評価指標と分析上の要確認事項

目標は実験計画書の6仮説。計画書の分析表に残る古い番号を修正して対応づけるが、未指定の測定条件を実装者が補わない。[計画書対応表のQ01〜Q07・Q09](20_experiment_plan_alignment.md#要確認事項) を参照する。統計手法・コード上の評価式は今回変更しない。

## 目標の六つの評価

| 仮説 | 目標の測定内容 | 現行で参照できる資料 | 確認が必要な条件 |
| --- | --- | --- | --- |
| 仮説1: 正答率の伸び | 再テスト正答率と事前テスト正答率の差を群間比較 | score_timeline_json.rounds、Attemptのphase/test_round/is_correct | 比較する再テストの回次、複数回の扱い、初期満点者と欠測（Q01） |
| 仮説2: 満点までの学習セッション回数 | 到達までに行った学習セッションの回数を比較 | TutorSession、学習負担ログ、終了理由・満点回答 | 用語別セッションか学習対象一巡か、未達・中断者（Q02） |
| 仮説3: 一用語当たりの周回数 | 学習確認の繰返し回数を比較 | 回答済みTutorTurn、grading_json、時刻 | 回答数・不正解数・再挑戦数、用語/参加者内集計、最大3回答との関係（Q03/Q09） |
| 仮説4: 同種誤答タイプの再選択率 | 事前でM1/M3だった回答と再テストの同タイプ選択を比較 | Attempt、recurrence_flag、misconception_timeline_json | 対象回次、分母、同一用語の重複、unknownへの変化（Q04） |
| 仮説5: 教材の主観評価 | 教材閲覧者の教材評価6項目を群間比較 | 現行は別内容の5段階仮アンケートのみ | 新アンケート未対応。閲覧判定、尺度端点、項目の合成方法（Q05） |
| 仮説6: 再テスト満点到達割合 | 満点到達者数/割当済み参加者数を群間比較 | 採点済み再テスト、Participantの群・終了理由、割付の運用記録 | 割当済みと登録済みの対応、final_test経路、中断・未回答（Q06） |

仮説一覧と意味は [研究条件](01_research_requirements.md) を正本とする。以前の初回再テスト限定、ループ数、再発率の3仮説をそのまま新番号へ流用しない。計画書の平均値・中央値や割合の記述を反映するが、新しい検定、合成式、補完法を決めない。

## アンケートの目標

- 経験の有無: チャット、プログラミング補助、CLI、APIによるAI利用の各経験。
- 1〜10段階: AI使用頻度、AIに関する自己評価、システムの操作しやすさ、システムのわかりやすさ。
- 教材評価6項目（1〜10段階）: わかりやすさ、読みやすさ、日本語のわかりやすさ、難易度の適切さ、学習への役立ち度、量の適切さ。
- 自由記述: 数値尺度とは別のテキスト回答として扱う。

これは主観評価であり、教材品質が学習効果を生んだという因果機序の証明ではない。非閲覧者を自動で0点にしない。6項目の平均・合計を採用するか、各項目を比較するかは未確定。端点・必須/任意・欠測の扱いも、記載がない部分を勝手に確定しない。

現行の画面とSurveyPayloadは1〜5で、教材評価6項目を独立して受け付け・保存・集計する契約ではない。既存5段階値を新尺度へ変換しない。画面・入力型・保存・CSV・集計の整合実装は未対応。

## 現行保存値の意味

再計算・群集計対象は実験仕様版3だけ。NULL・版1/2・未対応版は保存済み評価を閲覧/CSV出力し、再計算しない。実装は [experiment.py](../backend/app/services/experiment.py) のrecalculate_evaluation、_test_rounds、_learning_burdenを参照する。

| 保存名 | 現行の計算・用途 |
| --- | --- |
| pretest_score | 保存された事前回答のis_correctによる正答率 |
| retest_score | 保存されたretest回答全体の正答率。初回だけ・最終回だけではない |
| attainment_correct_rate | final_testがあればその正答率、なければ最新の再テスト満点バッチの正答率。仮説6の群別到達者割合とは異なる |
| same_misconception_recurrence_rate | 全retestのrecurrence_flag件数/事前M1・M3件数。同じ用語の反復を含み1を超える場合があり、参加者・用語単位の再選択割合と同一ではない |
| m1_recurrence_rate / m3_recurrence_rate | 再テストで当該タイプ再発があった用語数/当該タイプの事前件数。上の件数比とは集計粒度が異なる |
| score_timeline_json | 各テスト回の得点・事前比/前回比差分と、final_score_source等 |
| misconception_timeline_json | 用語別の各回の判定、解消・同種再発・別タイプ化等 |
| learning_burden_json | tutor_session_count、tutor_turn_count、retest_count、回答時間等。用語別セッション数・保存ターン数・テスト回次を混同しない |
| condition_check_json | 方略使用の確認と到達成績の測定元 |
| completed | 完了時刻がありgive_upではないか。単独では再テスト満点到達の証明にならない |

学習負担は未利用の先行生成を除外するが、tutor_turn_countは実学習セッション内の保存ターン数であり、必ず回答済み回数だけを意味するとは限らない。回答時間の合計も教材閲覧や実験全体の滞在時間と同一と断定しない。

attainment_correct_rateは物理列l0_correct_rateへ保存するが、現行の計算に廃止フェーズを使わない。旧値はlegacy_fieldsへ隔離し、統合CSV固定ヘッダ・生AIログを保持する。

## 分析と報告の境界

群別の参加者・完了者・回答数、正答/unknown率、タイプ出現数、学習回数と時間を集計する目標を記載する。ギブアップ・未回答は欠測/中断として別途報告し、具体的な分析対象や補完法はQ07で確認する。

内部final_testは事前満点者の最初の再テストで、学習後のretest満点者には重ねて出さない。測定経路、初期正答、試行機会、教材非閲覧を区別する。保存済み評価を新6仮説に適合した結果として再命名・再計算しない。
