# 事前アンケート（仕様版37）

## 適用範囲

新規参加者に仕様版37 / `experiment-plan-2026-11-04-presurvey-baseline-v2`を適用する。仕様版36以下は閲覧専用で保全し、既存参加者の進行・回答・評価を更新しない。登録後は同意→事前アンケート→事前テストの順に進む。事前アンケートが未完了の参加者は出題APIを利用できない。

## 事前アンケート

`presurvey-baseline-v2`として、既存の`ParticipantSurvey`へ`phase=presurvey`で保存する。新しいDB列は追加しない。

- `prior_term_knowledge`: 事前学習、ファインチューニング、RAG、プロンプトエンジニアリング、マルチエージェント、記憶プロセスの6項目。各項目は「知らない」「聞いたことがある」「意味を知っている」「説明できる」の4択で、全項目を必須とする。保存値はそれぞれ`unknown`、`heard_of`、`knows_meaning`、`can_explain`。
- `general_ratings`: 普段のAI利用頻度とAIを使いこなせているかの自己評価。各1〜10の整数で、両方必須。

仕様版36の`presurvey-baseline-v1`は「知っていた／知らない」のBoolean形式であり、過去回答はそのまま保全する。v1回答を新しい4段階尺度へ変換・補完しない。仕様版36以下は既存条件のまま閲覧専用とする。

送信は参加者・フェーズごとの冪等キーで保護する。同一内容の再送は保存済み応答を返し、異なる内容での再送は拒否する。保存成功後に`current_step=pretest`へ進む。

## 事後アンケート

新規送信は`posttest-10point-v3`とする。移動した事前知識6項目と一般評価2項目は含めない。システム評価（操作しやすさ、使い方のわかりやすさ）2項目と、教材評価6項目を各1〜10で保存し、自由記述は任意とする。教材を表示していない参加者の教材評価はnullで対象外、表示した参加者は6項目すべて必須。

既存のposttest v1/v2回答および旧列は変換・補完せず保全する。仮説5の教材評価指標は`phase=posttest`の回答だけを参照し、事前アンケートの値を混ぜない。

## 管理・出力

参加者ログとアンケートCSVでは、事前・事後の`phase`、アンケート版、回答JSONを区別して確認できる。統合ログでは事前アンケートを独立したsurveyイベントとして出力する。研究者は両フェーズを混同せず分析する。

同意画面および同意文書の表示は、事前アンケートを行う手続きを説明するために更新した。このアプリ内文書の更新は研究倫理審査・承認を意味しない。
