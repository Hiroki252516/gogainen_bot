# 04. Scaffolding and Tutoring

## 新しい足場掛けの扱い

現行実装では、学習セッション中に `L3`, `L2`, `L1` のようなヒント量レベルを動的更新しない。足場掛けは、以下の段階構造として扱う。

```text
前提用語理解
  ↓
概念理解
  ↓
支援なし再テスト
```

この方針は `revised_experiment_flow_term_concept_stages_FINAL.md` に基づく。旧設計のL3/L2/L1/L0列は、既存CSVや旧データ互換のためDBに残してよいが、現行の提案群学習ロジックでは使わない。

## 統制群

統制群は通常AIチューターとして動作する。

許可:

- RAG教材を根拠にした一般的な定義説明
- 簡単な例
- 自己説明を促す質問
- 一般的なフィードバック

禁止:

- 誤概念タイプを使った説明切替
- 前回回答や過去ログを使った個別化
- 前提用語リスト生成
- 用語理解ゲート
- L3/L2/L1の動的調整

## 提案群

提案群は前提用語ゲート型AIチューターとして動作する。

### 前提用語理解

- AIが対象概念理解に必要な前提用語を原則3件生成する
- 各前提用語に教材、確認質問、期待回答を持たせる
- 学習者は記述式で確認質問に答える
- 最大2回まで回答できる
- 1回目fail時は、より簡単な再説明と具体例を提示する
- 2回目fail時は、その対象概念を未通過として記録する

### 概念理解

- 全前提用語をpassした場合のみ開始する
- AIは前提用語を使った対象概念教材を提示する
- 学習者は前提用語を使って対象概念を説明する
- 最大4回まで回答できる
- fail時は、不足用語と直前関連用語に戻す
- 4回fail時は対象概念をfailとして記録し、次対象へ進む

## 誤概念タイプの使い方

M1〜M3は事前テスト診断として保存し、提案群の前提用語計画生成や説明方針に使う。学習中の各回答に対してM1〜M4を毎回判定し直さない。

被験者画面にM1〜M4を表示しない。学習者向けには、以下のような自然言語に変換する。

| 内部 | 学習者向け表現 |
|---|---|
| M1 | 概念を別の種類のものとして捉えている可能性があります |
| M2 | 似ている用語との違いを確認します |
| M3 | 言葉の表面ではなく、仕組みに注目して確認します |
| unknown | まず基本的な意味から確認します |

## RAG教材の扱い

両群とも `rag_ready_教材` のローカルRAG検索結果をAI payloadへ渡す。

- 統制群: RAG教材だけを根拠に一般説明を作る
- 提案群: RAG教材に加えて、事前テスト診断、学習対象理由、学習履歴を使う

AIには「教材コンテキストを優先し、教材にない内容は推測で断定しない」と指示する。

## 禁止事項

学習セッション、再テストを通じて以下を禁止する。

- 再テストの正解を直接教える
- 選択肢のどれが正解か教える
- M1〜M4を学習者画面へ出す
- 学習者の代わりに完成回答を書く
- 統制群に提案群用のログ適応情報を渡す

禁止要求への返答:

```text
この実験では、正解だけを提示することはできません。
代わりに、考えるための観点を1つ示します。
```
