# 04. Scaffolding and Tutoring

## Scaffolding

L3/L2/L1の動的変更は使用しない。足場掛けは次の段階と、提案群だけのログ適応教材で実現する。

```text
固定前提用語
  -> 概念フェーズ1: 教材あり
  -> 概念フェーズ2: 教材なし
  -> 全5概念再テスト
```

## AIの役割

AIが生成する:

- 前提用語教材
- フェーズ1教材
- 選択した誤答が不適切な理由
- 正答時・強制解決時の短い要点
- 問題バンク枯渇時だけ緊急問題

AIが決定しない:

- 通常問題
- 正答
- Mタイプ
- 次状態
- 評価指標

## Control Isolation

統制群教材payloadには、対象概念、現在の固定前提用語、RAG、現在選択した選択肢だけを含める。事前診断、過去選択、M遷移、戻り履歴を含めない。

## Proposed Adaptation

提案群教材payloadには、事前テストMタイプ、選択誤答、前提用語・フェーズ1・フェーズ2の履歴を含める。教材はM1ならカテゴリー再定位、M2なら境界比較、M3なら構造注目、unknownなら基礎説明を優先する。

## Answer Leakage

教材と未使用正答文を正規化比較し、完全包含、長い共通部分、類似度0.88以上を検出したら再生成する。3回失敗した場合は技術停止する。
