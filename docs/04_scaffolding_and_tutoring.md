# Scaffolding and Tutoring

学習セッションでは、旧 `term_understanding` / `concept_understanding` ではなく、`enrichment` / `conceptual_change` / `final_feedback` を使う。

| learning_stage | 表示名 | 役割 |
| --- | --- | --- |
| enrichment | 豊富化 | unknownまたはJ選択後に、不足している基礎知識を補う |
| conceptual_change | 概念変化 | M1/M3不正解後に、誤信念またはカテゴリー錯誤を修正する |
| final_feedback | 教材フィードバック | 学習内確認でA/B/C完全一致になった後のまとめ |

学習内確認で正解すれば `final_feedback` に進む。不正解がM1/M3なら `conceptual_change`、unknownなら `enrichment` に進む。

提案群では、M1/M3/unknownと過去ログを教材方略に反映する。統制群では同じステージ名をログに残すが、教材生成は `general_explanation` のままとし、M1/M3別の個別支援はしない。

被験者向け本文には内部ラベルを直接出さない。
