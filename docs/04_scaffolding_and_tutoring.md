# Scaffolding and Tutoring

学習セッションでは、誤答のタイプと学習段階に応じて教材生成の焦点を変える。固定問題の判定はbackendが行い、AIは決定済みの状態とRAG本文をもとに教材本文を生成する。

現行の固定10択問題では、M1・M3・unknownを選択肢から決定論的に判定する。M2・M4の定義と教材方略は実行時taxonomyとしてAI payloadへ渡されるが、現行固定問題の状態としては直接割り当てず、将来の診断問題設計用に保持する。

| learning_stage | 表示上の役割 | 支援の焦点 |
| --- | --- | --- |
| `enrichment` | 豊富化 | unknown・知識不足に対し、用語、構成要素、基本例を補う |
| `conceptual_change` | 概念変化 | M1〜M4に応じ、信念、モデル、カテゴリー、スキーマの誤りを修正する。現行の固定問題が直接割り当てるのはM1/M3で、M2/M4はtaxonomy・将来設計として保持する |
| `final_feedback` | 教材フィードバック | 確認問題後の短い要点整理 |

`L3`/`L2`は`scaffolding_level`に保存する内部互換・ログ値である。現行の参加者向け学習段階は上表の意味的な`learning_stage`で決まり、L3の学習を終えてL2へ進む固定の二段階フローは実装していない。

## Mタイプ別の教授方略

- M1: 明示的反証または暗黙的反証を使い、誤った単一命題と正しい命題を対比する。
- M2: 個別事実の訂正だけで終わらせず、モデルを支える中核前提を複数確認し、因果・構成関係を再構成する。
- M3: 表層的な類似性による分類を止め、何の種類の概念か、何ではないか、境界を示して正しいカテゴリーへ再配置する。
- M4: 欠けている概念ノードや関係を補い、新しいスキーマを例・関係・適用場面とともに構築する。
- unknown: 誤概念とは断定せず、基礎説明と具体例を優先する。

## control / proposed

両群で用語、学習段階、構成要素、固定確認問題、同一RAG検索結果を共有する。

- `control`: 学習者履歴、誤概念履歴、taxonomy、足場掛け情報をAI payloadへ含めず、`general_explanation` で生成する。
- `proposed`: 学習ログ、誤概念タイプ、足場掛けレベル、過去応答を追加し、Mタイプ別方略を生成する。

被験者向け本文にはMラベル、内部戦略、研究根拠を表示しない。テストフェーズでは教材、ヒント、即時正解を表示しない。
