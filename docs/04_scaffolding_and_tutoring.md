# 04. Scaffolding and Tutoring

## Scaffolding

旧来の足場掛けレベルとしてのL3/L2/L1の動的変更は使用しない。学習セッションの被験者向けフェーズ名として、L3（前提用語学習）とL2（概念理解フェーズ1）を使う。足場掛けは次の段階と、提案群だけのログ適応教材で実現する。

```text
L3: 前提用語学習
  -> L2: 概念理解フェーズ1（教材あり）
  -> 全5概念再テストループ
```

L3では、各対象概念に紐づく前提用語5件を順番どおり扱う。暫定運用では各前提用語につき必須小問は1問だけにし、誤答時は同じ小問スロットの別バリアントで最大3試行まで確認する。3回目も誤答した場合は強制解決として次の前提用語へ進める。

## AIの役割

AIが生成する:

- L3教材
- L2教材
- 選択した誤答が不適切な理由
- 正答時・強制解決時の短い要点
- 問題バンク枯渇時だけ緊急問題

学習者に表示する教材、誤答解説、正答要点はMarkdown本文として生成する。形式は短い見出し、箇条書き、太字、短い段落を中心にし、表、HTML、コードブロック、長大な連続段落は使わない。

AIが決定しない:

- 通常問題
- 正答
- Mタイプ
- 次状態
- 評価指標

## Control Isolation

統制群教材payloadには、対象概念、現在の固定前提用語、RAG、現在選択した選択肢だけを含める。事前診断、過去選択、M遷移、戻り履歴を含めない。

## Proposed Adaptation

提案群教材payloadには、初期テストMタイプ、選択誤答、L3/L2の履歴、再テスト誤答、内部用の `misconception_taxonomy` と `teaching_guidelines` を含める。教材はM1ならカテゴリー再定位、M2なら境界比較、M3なら構造注目、unknownなら基礎説明を優先する。taxonomyはAIの内部基準であり、被験者画面にはMラベルや研究名を出さない。概念フェーズ2は今回の参加者フローでは使わない。

実行時taxonomyの要点:

- M1: 誤った上位カテゴリーから正しいカテゴリーへ再定位する
- M2: 似た概念との境界を、役割、入力、処理、出力、使う場面で対比する
- M3: 表層語やキーワードではなく、原理、構造、判断基準へ注意を向ける
- unknown: 誤概念扱いせず、前提知識不足として基礎説明から始める

## Answer Leakage

教材と未使用正答文を正規化比較し、完全包含、長い共通部分、類似度0.88以上を検出したら再生成する。3回失敗した場合は技術停止する。
