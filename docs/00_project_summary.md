# 実験の概要と現行仕様

## 共通の用語注釈

仕様版18でも、版8で追加した両群・両問題版共通の用語注釈を維持する。今回は通常版memory_process・learning_round_v2だけを献立提案AIの指定文へ改訂し、場面説明と設問の2段落で表示する。残り8確認問題、易しい版、各テストと訂正情報、AI指示・生成契約・採点・回数上限・評価式は変更しない。記憶V1の3段落とマルチエージェントV2/V3の表示も維持する。新規通常版は学習バンクv11、易しい版は4を使い、旧v3・v5・v6・v7・v8・v9・v10と既存記録を保持する。通常経路で当該用語の2回目の学習にV2を使い、同じセッション内の2回目の回答とは区別する。[今回の全文・分類理由と検証条件](31_memory_round_two_revision.md)・[記憶V1](30_memory_confirmation_revision.md)・[テスト全文](21_assessment_action_questions.md)を参照する。文長均一性・分類妥当性・初心者への理解しやすさを保証せず、教材600〜800文字と別枠の共通注釈を維持する。[辞書全文](24_learning_glossary.md)。

Word「卒業研究計画書_6.7挿入済み.docx」とユーザー承認済み実装計画を根拠とする。出典・確定判断・残課題は[20](20_experiment_plan_alignment.md)、指標は[12](12_evaluation_metrics.md)。

## 研究と実装

- 比較は履歴を使う通常AIチューター（control）と、明示的診断・修正対象・訂正情報・taxonomy・タイプ別教授方針を追加するAIチューター（proposed）。統制群の自然な誤り訂正を許容する。
- 対象3概念：llm_knowledge、multi_agent、memory_process。大学生40名/各群20名・原則無作為割付を目標とし、アプリは研究者のA/Bコードを使用する。
- 6仮説：初回の正答率の伸び、満点までの用語別セッション数、用語内不正解数、同種誤答再選択率、教材評価、満点到達割合。記述集計のみ。
- backendが固定採点・分類・方略決定を行う。M1/M3/unknown、M3優先。AIは教材・正答要約・誤答解説のみ。
- 共通説明とunknownは意味や仕組みを説明する。unknownは定義・仕組み・教材内適用確認を本文証拠で検査し、旧6項目を必須としない。
- 両群とも600〜800文字・自由な章立て。実験群の本文証拠検査は意味的な正しさや理解の証明ではない。
- アプリ側既定はgpt-6-luna / low。管理画面でgpt-6.1-sol / gpt-6-lunaを一時切替できる。設定はbackendプロセス内だけに保持し、次回呼び出しから両群・進行中参加者に適用、再起動で環境値へ戻る。実験中の変更は同一参加者内のモデル混在を生み得るため、収集時は固定する。研究計画書原本にはgpt-5.6-luna / lowと記載されており、Wordは変更していない。アプリ標準条件との一致を警告・実送信監査で識別する。実AI失敗時にMockへ切り替えない。
- アンケートは経験4有無、一般4/教材6の1〜10、必須自由記述。教材未表示者の6項目は自動対象外。

## 版・保存・フロー

実験仕様版は18、新規protocol_idはexperiment-plan-2026-10-26-memory-round2-v1。既存版17以下、NULL、未対応protocol_idの記録は進行・削除・補修・再計算・集計を行わず、閲覧・CSV出力で保全する。旧行へ識別子や再テスト回数を補完しない。

テストは9固有問題（事前3＋事前後2回×3）。内部final_testはretest_v1を共用し、次はretest_v2。事前後のテストはfinal_test込み最大2回、事前込み最大3回とし、満点または2回目未達でアンケートへ進む。学習確認v11の9問は維持するが、新規経路の学習は最大2セッション/用語で3セッション目には到達しない。同一セッション内は最大3回答。通常経路の最大はテスト9＋学習6＝15固有問題、採点回答イベント27回である。問題文・分類根拠は[21](21_assessment_action_questions.md)を参照する。

material-viewの初回表示時刻から実績を数え、未利用の先行生成を学習回数・教材表示者へ算入しない。新アンケート・指標は版付きJSONへ保存し、旧5段階値や既存評価列を変換しない。
