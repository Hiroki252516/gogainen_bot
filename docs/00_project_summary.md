# 実験の概要と現行仕様

## 共通の用語注釈

仕様版22でも両群・両問題版共通の用語注釈を維持する。通常版の初回確認問題で、multi_agentのG（M3）とmemory_processの場面説明後半・F（M1）・H（M3）の4か所だけを指定文へ改訂する。Gは検索ツールとAIエージェント、Hは同じ会話の履歴利用と会話をまたぐ長期記憶の混同として扱う。Fは記録を与えて希望どおり回答できたことから次回の記録参照も不要と判断する誤りであり、本文にない重み更新を補わない。既存判定、記憶V1の3段落表示、対象2問の指定外部分と残り7確認問題、全テスト・訂正情報・易しい版・教授プロンプト・注釈・採点・配置・回数上限を維持する。新規だけ仕様版22・通常版学習14（易しい版4）と現行protocolを保存する。旧学習v13以前を保持し、旧仕様版21以下は閲覧専用で記録を付け替えない。同期生成・先行生成は保存版に統一し、履歴はsnapshot優先・当時の学習版で復元する。通常版テストscenario-actions-v6とDB問題ID、公開API・DB構造・AI生成契約は変更しない。[今回の本文・分類理由・保存と検証条件](35_multi_memory_round_one_revision.md)を参照する。教材600〜800文字は維持する。

Word「卒業研究計画書_6.7挿入済み.docx」とユーザー承認済み実装計画を根拠とする。出典・確定判断・残課題は[20](20_experiment_plan_alignment.md)、指標は[12](12_evaluation_metrics.md)。

## 研究と実装

- 比較は履歴を使う通常AIチューター（control）と、明示的診断・修正対象・訂正情報・taxonomy・タイプ別教授方針を追加するAIチューター（proposed）。統制群の自然な誤り訂正を許容する。
- 対象3概念：llm_knowledge、multi_agent、memory_process。大学生40名/各群20名・原則無作為割付を目標とし、アプリは研究者のA/Bコードを使用する。
- 6仮説：初回の正答率の伸び、満点までの用語別セッション数、用語内不正解数、同種誤答再選択率、教材評価、満点到達割合。記述集計のみ。
- backendが固定採点・分類・方略決定を行う。M1/M3/unknown、M3優先。AIは教材・正答要約・誤答解説のみ。
- 共通説明とunknownは意味や仕組みを説明する。unknownは定義・仕組み・教材内適用確認を本文証拠で検査し、旧6項目を必須としない。
- 両群とも600〜800文字・自由な章立て。実験群の本文証拠検査は意味的な正しさや理解の証明ではない。
- アプリ側既定はgpt-6-luna / low。管理画面でgpt-6.1-sol / gpt-6-lunaを一時切替できる。設定はbackendプロセス内だけに保持し、次回呼び出しから両群・進行中参加者に適用、再起動で環境値へ戻る。実験中の変更は同一参加者内のモデル混在を生み得るため、収集時は固定する。研究計画書原本にはgpt-5.6-luna / lowと記載されており、Wordは変更していない。アプリ標準条件との一致を警告・実送信監査で識別する。実AI失敗時にMockへ切り替えない。
- アンケートは経験4有無、一般4/教材6の1〜10、必須自由記述。教材未表示者の6項目は自動対象外。

## 版・保存・フロー

実験仕様版は22、新規protocol_idはexperiment-plan-2026-10-27-multi-memory-round1-v1。既存版21以下、NULL、未対応protocol_idの記録は進行・削除・補修・再計算・集計を行わず、閲覧・CSV出力で保全する。旧行へ識別子や再テスト回数を補完しない。

テストは9固有問題（事前3＋事前後2回×3）。内部final_testはretest_v1を共用し、次はretest_v2。事前後のテストはfinal_test込み最大2回、事前込み最大3回とし、満点または2回目未達でアンケートへ進む。学習確認v14の9問は維持するが、新規経路の学習は最大2セッション/用語で3セッション目には到達しない。同一セッション内は最大3回答。通常経路の最大はテスト9＋学習6＝15固有問題、採点回答イベント27回である。問題文・分類根拠は[21](21_assessment_action_questions.md)を参照する。

material-viewの初回表示時刻から実績を数え、未利用の先行生成を学習回数・教材表示者へ算入しない。新アンケート・指標は版付きJSONへ保存し、旧5段階値や既存評価列を変換しない。

現行版22は通常版と易しい版を並行保持する。管理設定を登録時に固定し、各版内で両群を比較・集計する。易しい版は問題と説明条件の両方を平易化する。[運用と契約](22_question_set_modes.md)・[問題全文](23_easy_question_bank.md)を参照する。
