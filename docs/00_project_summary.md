# 実験の概要と仕様書の読み方

目標仕様の根拠は2026-10-18確認の実験計画書。出典の指紋、計画書の節との対応、現行実装との差分は [計画書対応表](20_experiment_plan_alignment.md) にまとめる。文書更新は実装済み・実験開始可能を意味しない。

## 目標仕様

- 比較は回答履歴を使う通常AIチューター（統制群/control）と、共通履歴に明示的な誤概念対応を追加するAIチューター（実験群/proposed）。
- 対象はllm_knowledge、multi_agent、memory_processの3概念。大学生40名、各群20名を目標とし、原則無作為に割り当てる。
- 仮説は正答率の伸び、満点までの学習セッション回数、用語当たりの周回数、同種誤答の再選択率、教材評価、再テスト満点到達割合の6つ。[研究条件](01_research_requirements.md) に記載する。
- 両群が同じ種類・取得規則の用語説明、RAG、採点済み回答履歴を利用する。実験群だけに診断・具体的な誤答対象と訂正情報・taxonomy・タイプ別教授指針を追加する。
- 教材と回答後解説はAI生成、問題と採点は固定。教材は600〜800文字で章立てはAIが決める。モデルはgpt-5.6-luna / lowを予定する。
- unknownでは特定の誤概念を仮定せず意味や仕組みを説明する。統制群の自然な誤り訂正・反駁は許容する。
- 事後アンケートは経験の有無、1〜10段階の評価、教材評価6項目、自由記述を扱う。未確定の尺度・集計条件は [評価指標](12_evaluation_metrics.md) を参照する。

## 現行実装と未対応

現行の実験仕様版は3。新規参加者だけが進行でき、NULL・版1/2・未対応版の試用は閲覧専用。分類はM1/M3/unknown、理解状態はstable_correct/misconception/unknown。旧分類・旧支援量・独立した追加評価は復活させない。

テスト21問（事前3・再15・最終3）、学習確認v2の30問を使用する。A〜Iから3つまたはJのみを選び、正解3つの完全選択とM3優先で採点する。各用語最大3回答。内部final_testは事前全問正解者の最初の再テストであり、全員が共通の最終テストを受けるわけではない。

現行unknownは6項目必須、共通説明は定義・仕組み/役割・具体例・注意点を要求する。統制群の指示に診断用語が残り、推論既定値はmedium、アンケートは5段階の仮フォーム。これらと6仮説の評価対応は未対応・要確認として区別する。

API、DB、プロンプト、環境設定、実行版の値は今回変更しない。研究ログ、実AI応答、正確な遷移を優先し、app-server失敗時にMockへ自動フォールバックしない。本文証拠の機械検査は説明の事実的正しさまで保証しない。

**開始前の注意:** A〜C正解、D〜F=M1、G〜I=M3、J=unknownは一時デバッグ配置であり復旧が必要。管理機能の認証・権限確認も未実装。[受け入れ検証](14_testing_acceptance.md) と [運用手順](19_experiment_operation_runbook.md) を確認する。旧案はdocs/historyに保全する。
