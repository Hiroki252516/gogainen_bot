# Project Summary

本リポジトリは、卒業研究用AIチューターの仕様・実装リポジトリである。比較対象は「通常AIチューター」と「ログ適応型AIチューター」であり、提案群だけが誤概念タイプ、過去ログ、足場掛け履歴を教授方略に使う。

## Current MVP

- 対象用語は `transformer` のみ。
- テスト問題は10択・3つ選択式。
- 正解はA/B/C完全一致のみ。
- 誤概念分類は M1、M3、unknown を扱う。
- M2/M4はDB互換値として残してよいが、seed・画面・判定・研究ログの主導線では新規生成しない。

| ラベル | 名称 | 概要 |
| --- | --- | --- |
| M1 | 誤信念型 | TransformerやAttention/FFNを、人間の理解・思考・判断として捉える |
| M3 | カテゴリー錯誤型 | Transformerをモデルアーキテクチャではなく、アプリ・機能・知能主体として捉える |
| unknown | 知識不足 | わからない、または判断に必要な知識が不足している |

## Flow

事前テストでTransformer問題を出し、不正解またはunknownを学習対象にする。M1/M3は `conceptual_change`、unknownは `enrichment` に進める。学習内確認で正解すれば `final_feedback`、不正解なら分類に応じて `conceptual_change` または `enrichment` へ戻る。再テスト・最終テストは事前テストと同じ問題文・選択肢セットを使う。

被験者向け文面にはM1/M3などの内部ラベルを直接出さない。
