# 00. Project Summary

## システム名

学習ログ駆動型AIチューター  
英語名: Learning-Log-Driven AI Tutor

## 研究テーマ

AI関連専門用語の概念理解における、誤概念再発抑制と支援なし転移を目的とした、学習ログ駆動型AIチューターの設計と評価。

## システムの中核

学習者がAI・情報系専門用語の問題に回答する。システムは回答を正誤判定するだけでなく、誤答の背景にある誤概念タイプを分類する。その後、誤概念タイプと過去ログに基づき、教授方略と足場掛けレベルを決定する。学習者はAIチューターの支援を受けながら学習し、再テストと転移テストで理解の定着を測る。

## 研究上の最重要ポイント

通常のAIチューターとの差は、「AIを使うかどうか」ではない。差は「ログを使って支援を変えるかどうか」である。

### 統制群

- 誤答に対して一般的な解説を提示する
- 過去ログを支援方針に使わない
- 誤概念タイプに応じた教授方略の切り替えをしない
- 足場掛けレベルを動的に調整しない

### 提案群

- 事前テスト・学習セッション・再テストのログを保持する
- 誤概念タイプを M1〜M4 に分類する
- 誤概念タイプに応じて教授方略を切り替える
- 理解が進めば L3 → L2 → L1 → L0 と足場掛けを減らす
- 同じ誤概念が再発した場合は、足場掛けレベルを維持し、教授方略を変更する

## 主評価指標

| 指標 | 意味 |
|---|---|
| 同種誤答再発率 | 事前テストで出た誤概念と同じタイプの誤りが再テストで再び出た割合 |
| 足場掛けなし自力解答率 | L0条件、つまりヒントなしで正答できた割合 |
| 足場掛けなし転移率 | 学習時とは異なる文脈の問題に、ヒントなしで正答できた割合 |

## 実装で守るべき思想

- AIの返答は研究ログとして保存する
- AIの判断は必ず構造化JSONとして保存する
- 学習者画面にはM1〜M4などの内部ラベルをそのまま出さない
- 実験条件を壊さないように、自由チャットは制御する
- 最終的にCSVで実験分析できるようにする
