# 00. Project Summary

## システム名

学習ログ駆動型AIチューター  
英語名: Learning-Log-Driven AI Tutor

## 研究テーマ

AI・情報系専門用語の概念理解において、事前テストで得た誤概念タイプ診断をもとに、前提用語理解、教材あり概念理解、教材なし概念説明へ段階的に進ませるAIチューターを設計・実装・評価する。

## 背景

AI・情報系専門用語は、日常語としても使われる語や、近い意味に見える語が多い。たとえば `Attention` は日常語では「注意」だが、Transformerでは入力中のトークン間関係を重み付けして利用する計算機構である。単語を見たことがあることと、専門分野の概念として使えることは別である。

通常の解説では、学習者がその場で納得したように見えても、前提用語を理解しないまま対象概念だけを暗記している可能性がある。本研究は、対象概念を直接説明する前に必要な前提用語を確認し、その後に対象概念を自分の言葉で説明できるかを測る。

## システムの中核

学習者は5概念の事前テストに回答する。システムは回答を正誤判定し、誤答選択肢に紐づくM1〜M3またはunknownを初期誤概念として保存する。正答以外の概念は学習対象になる。

比較対象は「AIあり/なし」ではなく、以下の二群である。

- 統制群: RAG教材を根拠にした一般小問3件、概念フェーズ1、概念フェーズ2を行う。
- 提案群: 事前テスト診断と学習ログを使い、前提用語理解、概念フェーズ1、概念フェーズ2へ進む3段階適応型学習を行う。

提案群では、旧設計のように学習中にM1〜M4を毎回再判定したり、L3/L2/L1の足場掛けレベルを動的更新したりしない。足場掛けは、前提用語理解、教材あり概念理解、教材なし概念説明、支援なし再テストという段階構造として扱う。

## 最終誤概念分類

| Final | 名称 | 役割 |
|---|---|---|
| M1 | カテゴリー誤分類型 | 概念を本来とは異なる種類のものとして捉えている |
| M2 | 類似概念境界混同型 | 似た概念との違いや境界を区別できない |
| M3 | 表層特徴・キーワード反応型 | 問題文の表面的な単語や語感に反応している |
| M4 | 文脈転移失敗型 | 将来の転移テスト拡張用。現行フローでは主評価に含めない |

現行MVPでは事前テスト・再テストの選択肢にM1〜M3とunknownを持たせる。M4は互換列として残すが、転移テストを実施しないため主要判定には使わない。

## 主評価指標

| 指標 | 意味 |
|---|---|
| pretest_score | 事前テスト正答率 |
| retest_score | 再テスト正答率 |
| same_misconception_recurrence_rate | 事前テストと同じM1〜M3誤答が再テストで再発した割合 |
| prerequisite_pass_rate | 前提用語/小問を通過した割合 |
| concept_pass_rate | 学習セッションが最終的にcompletedになった割合 |
| concept_phase2_success_rate | 教材なし概念説明を通過した割合 |

旧指標のL0正答率、転移率、M4転移失敗率は互換列として残すが、現行参加者フローの主評価には含めない。

## 初期実装スコープ

対象概念は現行5概念を維持する。

1. Transformer
2. Attention
3. LLMの学習段階
4. 事前学習
5. 事後学習

追加候補はLoss、ハルシネーション、正則化である。追加候補はデータモデルとseedで拡張可能にするが、MVPの必須対象にはしない。
