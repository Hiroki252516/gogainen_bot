# 現行実験の概要

実験仕様版は `3`。現行の実装とこの版の文書を正本とする。旧設計は [履歴資料](history/2026-10-06/00_project_summary.md) に保存しており、実行要件ではない。

- 対象概念は `llm_knowledge`、`multi_agent`、`memory_process` の3つ。
- 比較は共通履歴を使う通常AIチューター（control）と、同じ共通履歴に明示的な誤概念対応を追加するAIチューター（proposed）。両群とも同じ実AI・共通RAG・診断連動の確認問題規則を利用する。
- 分類は M1（単一命題の誤り）、M3（カテゴリー誤り）、unknown（知識不足）。理解状態は `stable_correct`、`misconception`、`unknown`。
- 問題はYAML/backendで固定し、AIは教材と即時解説だけを生成する。
- 事前3問、再テスト3問×5 variant、最終3問の計21問。学習確認は現行v2の30問のみ。
- A〜Iから3つ、またはJのみを選ぶ。正解3つの完全選択だけが正解。M3優先判定を維持する。
- A〜C正解、D〜F=M1、G〜I=M3、J=unknownは一時的なデバッグ配置。研究データ収集前に分散を復旧する。

新規参加者だけに `experiment_spec_version=3` を保存する。NULL・仕様版1/2・未対応版は閲覧専用で、記録・完了状態を変更しない。独立した追加評価フェーズは設けず、教材内の適用確認 `transfer_check` は維持する。

両群の教材章立てはAI生成とする。冒頭の用語見出し・非空の小見出し節を維持し、必須教授内容は節本文の証拠で検証する。見出しの文言・数・順序・内容のまとめ方を固定しない。

研究ログ、実AI応答、実験遷移を優先する。OpenAI APIキーを要求せず、Codex app-server未接続時はMockへ自動フォールバックしない。
