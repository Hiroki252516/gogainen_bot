# 記憶プロセスPRETEST選択肢の追加改訂（仕様版33）

## 適用版と履歴

仕様版33 / `experiment-plan-2026-11-01-pretest-content-revision-v2`の新規参加者から、通常版テストバンク`split-actions-v3`を適用する。仕様版32以下は閲覧専用とし、既存の問題・回答・snapshot・評価を変更しない。版管理は仕様版27〜31を`split-actions-v1`、仕様版32を`split-actions-v2`、仕様版33を`split-actions-v3`とする。

仕様版32の改訂内容・原本は[44](44_pretest_content_revision.md)に保持する。仕様版33はv2の複製を基に、以下の3本文だけを変更する。場面文、設問文、選択肢の役割・ラベル・順序、正答、設問3のデータ、6設問形式、4択単一選択、採点方法は変えない。

## 変更内容

通常版の記憶プロセスPRETEST設問1「希望の保存と利用」:

- M1（表示ラベルB）を「利用者が『辛い料理は避けたい』と伝えた会話を利用者ごとに全文保存し、次の相談ではAIが保存された会話から必要な希望を自動的に見つけて使えると考え、過去の記録を検索してAIに渡す仕組みは設けない。」へ変更する。

通常版の記憶プロセスPRETEST設問2「希望の変更」:

- M1（表示ラベルB）を「利用者が『辛い料理は避けたい』という希望を『少し辛い料理も食べたい』に変更した場合、新しい希望をAIに伝えて献立を作らせれば、以前に保存した希望の記録も新しい内容に書き換わると考え、記録を更新する処理は設けない。」へ変更する。
- M3（表示ラベルC）を「利用者が『辛い料理は避けたい』から『少し辛い料理も食べたい』に希望を変更した際、AIがすべての利用者に共通して使う指示文を『少し辛い料理も提案する』に変更し、この設定を、利用者ごとの希望を記憶する仕組みとして利用する。」へ変更する。

## 維持する動作

- RETEST1、RETEST2、内部`final_test`の設問・選択肢は仕様版32のv2と同一とする。
- 誤答したPRETEST設問を学習確認で再提示する場合は、回答時に保存した問題本文・選択肢snapshotを再利用する。seed後に旧問題を更新・削除しない。
- 既存の採点、回答保存、結果表示、API、DB構造は変更しない。
- 仕様版32の参加者は現行仕様版境界により閲覧専用となる。過去の回答履歴は保存時に紐づく問題IDとsnapshotで参照する。

## 受入検証

- v1・v2のファイルを変更せず、v3がv2から指定3本文のみ変更された内容であることを比較する。
- RETEST1/2がv2と一致し、選択肢の分類・ラベル・順序・正答が維持されることを確認する。
- 隔離DBで仕様版32のv2問題と仕様版33のv3問題が別construct keyで保存され、旧参加者・Attempt・snapshotがseed再実行後も保持されることを確認する。
- 仕様版33の学習確認では保存済みPRETEST snapshotがライブバンクの再取得より優先されることを確認する。
- 受入結果と実行環境は[14](14_testing_acceptance.md)に記録する。自動比較は選択肢の研究的妥当性、読みやすさ、難易度同等性、学習効果を実証するものではない。
