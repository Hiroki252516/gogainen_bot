# 用語辞書v3と教材内の言い換え（仕様版31）

この文書は仕様版31の辞書・生成指示の履歴である。ここに記載したモード別文字数条件は仕様版41で廃止され、現行の目標と監査契約は[42](42_learning_glossary_material_length.md)に従う。仕様版41の新規参加者にも、定義の意味を参照して自然に言い換える指示は維持する。

## 適用

仕様版31 / `experiment-plan-2026-10-31-glossary-definition-paraphrase-v1`から、新規参加者へ辞書v3を適用する。仕様版30以下、旧protocol、NULL・未対応版は閲覧専用とし、既存の参加者、回答、教材、評価、辞書snapshotを変更・再生成しない。DB構造、辞書の返却形式、抽出規則、採点、群別教授方針は変更しない。

辞書正本は`backend/app/seed/content/learning_glossary_v3.yml`。v2は`learning_glossary_v2.yml`にそのまま保持し、旧snapshotの再表示に使う。v3では「追加学習」「重み」「エージェント」「モデル」の定義だけを更新し、他の辞書項目、別表記、出典、除外語を維持する。

## 教材生成

登録時に`integrated_material`を選んだ参加者の教材生成だけ、v3の辞書情報を`glossary_reference`として両群共通入力に渡す。定義文は逐語転記のための文案ではなく、意味を照合する参考情報として扱うよう指示する。教材本文では実際に使用する登録語だけを対象にし、初出時に文脈に沿った自然な言葉で説明する。中心的な意味を保ち、定義にない性質・断定を足さない。教材内で辞書の全項目を列挙しない。

仕様版31当時は教材本文のモード別文字数条件（annotation_only 600〜800、integrated_material 600〜1200）を維持した。辞書情報は両群へ同じ形で渡し、proposed専用の診断・分類・教授方針は従来どおりcontrolへ混入させない。`annotation_only`では辞書をAI入力へ渡さず、教材注釈欄を表示した。`integrated_material`では教材用注釈欄を隠した。回答後解説・テストの注釈はv3定義を使うが、保存済みsnapshotは過去の辞書版・説明を維持する。

## 辞書の更新内容

| 用語 | v3の定義 |
| --- | --- |
| 追加学習 | 既に学習したAIに、新しい学習用データを使ってさらに学習させ、回答の仕方などを目的に合わせて調整すること |
| 重み | AIが文章を作るための計算に使う数値です。学習によってこの数値が調整されると、AIが選ぶ言葉や回答の仕方が変わることがある |
| エージェント | 与えられた目的に向けて、状況を見ながら次の行動を判断して進めるAI |
| モデル | AI本体を指す |

これらの定義文は注釈表示にそのまま使われる。言い換えの指示は教材内解説の生成本文だけに適用する。

## 検証上の制約

自動テストは辞書版・定義文・v2保持、生成入力の共通性、言い換え指示、既存snapshotの再現を確認する。実AIが毎回自然に言い換えること、個々の説明の意味的な正確さ、初学者の理解や学習成果への効果は自動テストだけでは実証しない。実AIを用いた内容確認・研究者レビュー・予備調査は別途必要である。
