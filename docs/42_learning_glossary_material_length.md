# 教材内解説モードの文字数条件（仕様版30）

## 適用条件

仕様版30 / `experiment-plan-2026-10-31-learning-glossary-material-length-v1`で導入した文字数契約は、仕様版32でも維持する。教材生成の文字数契約を参加者に登録された`learning_material_glossary_mode`で分ける。文字数はMarkdown記号を含む`tutor_message`本文の文字数であり、見出し・用語解説も本文に含める。

| 教材モード | 目標 | 許容範囲 |
| --- | ---: | ---: |
| `annotation_only`（注釈欄のみ） | 700文字前後 | 600〜800文字 |
| `integrated_material`（教材内解説） | 1000文字前後 | 600〜1200文字 |

教材内解説モードは辞書登録語の説明を本文に含めるため、許容上限を1200文字へ広げる。下限は両モード共通で600文字とする。教材内解説モードでも辞書の全語を列挙せず、本文で実際に使う登録語を説明する既存ルールを維持する。

## 生成・検証・監査

生成prompt、教材生成後の文字数検証、範囲外の再生成指示、AI呼び出しの出力指標・TutorTurnの検証記録は、同一のモード別契約を使う。範囲外は同じAI backendで初回を含む最大3試行まで再生成し、なお不合格の場合に教材を確定しない。実測文字数、目標・上下限、試行ごとの検証結果を既存の監査JSONへ記録する。DB列と公開APIの構造は追加しない。

版30当時の適用対象は版30の新規参加者、現行仕様版32では版32の新規参加者である。仕様版31以下の参加者は閲覧専用で、保存済み教材、snapshot、監査記録を更新・再生成しない。文字数検査は長さの機械的な適合だけを示し、説明の正確さ、初心者の理解、学習効果を証明するものではない。現行コードの受入検証は[14](14_testing_acceptance.md)、AI生成契約は[10](10_ai_prompt_contracts.md)、仕様版31の定義言い換えは[43](43_glossary_definition_paraphrase.md)を参照。
