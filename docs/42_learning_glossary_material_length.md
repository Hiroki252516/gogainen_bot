# 教材の目標文字数と履歴

## 現行条件（仕様版43）

仕様版43 / `experiment-plan-2026-11-08-basic-understanding-question-mode-v1`でも、新規参加者の教材本文はMarkdown記号を含めて800文字程度を目安に生成する。教材内解説が標準であり、辞書語の説明も本文に含めて数える。統制群には群別の自然言語方略指示を加えず、提案群には診断・教授方略指示を加える。問題モード設定は教材の生成条件を変更しない。

文字数の上下限は設けない。目標値から外れても長さだけを理由に生成を拒否・再試行せず、他の構造・教材契約・安全性検証は従来どおり行う。教材本文の実文字数と目標値は監査用に記録するが、範囲内外の判定は記録しない。

仕様版42以下の参加者は閲覧専用で、保存済み教材・snapshot・監査記録を再生成・変更しない。過去のAIログに記録された目標・上下限は当時の記録として保持し、仕様版43の条件へ書き換えない。文字数の目安は教材の内容や意味的な正確さ、初心者の理解、学習効果を保証するものではない。

## 仕様版39の履歴条件

仕様版39では教材内解説を目標1000文字・許容600〜1200文字、既存の注釈欄のみモードを目標700文字・許容600〜800文字としていた。統合前の仕様版40では、目標800文字protocolが上下限と範囲外再生成を廃止した一方、統制群共通prompt protocolは従来の長さ条件を維持した。統合後の仕様版41からは上下限を使った生成後検証と範囲外の再生成を行わない。保存済み教材・AIログの値は変更しない。

## 生成・監査

生成promptは目標文字数だけを指示する。検証失敗時の再生成は教材構造・必須教授内容・安全性など、文字数以外の既存条件に限る。Mock生成は再現性のため目標値を使うが、生成結果に上下限を設けない。

監査記録では実文字数、目標文字数、段落数、箇条書き数、他の生成検証結果と試行数を確認できる。文字数の実測は説明内容の質や学習効果の代理指標ではない。

仕様版30で導入したモード別文字数契約と当時の検証履歴は[実験計画との対応](20_experiment_plan_alignment.md)および[受入記録](14_testing_acceptance.md)に保存する。教材モード・辞書参照の詳細は[41](41_learning_glossary_material_mode.md)、AI契約は[10](10_ai_prompt_contracts.md)を参照。
