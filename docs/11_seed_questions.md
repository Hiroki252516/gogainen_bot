# Seed Questions

このファイルは `backend/app/seed/data.py` の現行seedと同期する。現在のMVP対象用語は2語である。

## 対象用語

1. `transfer_learning`: 転移学習
2. `llm_training_process`: LLMの学習段階

過去仕様ではTransformer、Attention、事前学習、事後学習を含む5語構成を想定していたが、現行実装では非active扱いまたは拡張候補とする。

## Q1 転移学習

- slug: `transfer_learning`
- description: あるデータやタスクで学習済みのモデルや特徴を、別の関連タスクの学習に活用する方法。少ないデータでも効率よく性能を高めやすい。
- keywords: 学習済みモデル, 別タスク, 活用, 効率

### Pretest

転移学習の説明として、最も適切なものはどれか。

- A. あるデータやタスクで学習済みのモデルや特徴を、別の関連タスクの学習に活用する方法。 (correct)
- B. 学習データを別の保存場所へ移動する作業のこと。 (M1)
- C. 事前学習と同じで、大量データからゼロから基盤モデルを作ることだけを指す。 (M2)
- D. transferという語があるので、翻訳やファイル転送の機能そのものを指す。 (M3)
- E. わからない。 (unknown)

Expected: あるデータやタスクで学習済みのモデルや特徴を、別の関連タスクの学習に活用する方法。

### Retest

転移学習が有効な場面として、最も適切なものはどれか。

- A. 関連するタスクで学習済みのモデルを出発点にして、少ないデータの新しいタスクへ適応させる場面。 (correct)
- B. 学習済みデータを別のフォルダへコピーして、モデルの性能を上げる場面。 (M1)
- C. どのタスクでも必ずゼロから大規模データで学習し直す場面。 (M2)
- D. 英語のtransferという名前から、文章を別言語へ翻訳する場面だけ。 (M3)
- E. わからない。 (unknown)

Expected: 関連するタスクで学習済みのモデルを出発点にして、少ないデータの新しいタスクへ適応させる場面。

### L0 Check

転移学習を、学習済みモデルと別タスクへの活用に触れて説明してください。

### Final Test

画像分類で、大規模画像データで学習済みのモデルを使い、少量の医療画像データに合わせて調整する。これは何の例として最も適切か。

- A. 転移学習。学習済みモデルを関連する別タスクへ活用しているため。 (correct)
- B. データ転送。画像ファイルを別の場所へ移しているため。 (M1)
- C. 事前学習そのもの。少量データで別タスクに合わせる点は関係ないため。 (M2)
- D. 翻訳処理。transferという語は翻訳を意味するため。 (M3)
- E. わからない。 (unknown)

Expected: 転移学習。学習済みモデルを関連する別タスクへ活用しているため。

### Transfer

少量の専門分野データしかない分類タスクで、一般画像で学習済みのモデルを出発点にする理由を説明してください。

## Q2 LLMの学習段階

- slug: `llm_training_process`
- description: LLMの主な学習プロセスは、事前学習、インストラクションチューニング、事後学習に分けられる。
- keywords: 事前学習, インストラクションチューニング, 事後学習

### Pretest

対象範囲で説明されているLLMの主な学習プロセスの組み合わせとして、最も適切なものはどれか。

- A. 事前学習、インストラクションチューニング、事後学習。 (correct)
- B. 入力、思考、感情、会話という人間の学習段階。 (M1)
- C. プロンプト、コンテキストウィンドウ、Function Calling。 (M2)
- D. 『事前』『事後』という語があるので、学習前と学習後のテストだけを指す。 (M3)
- E. わからない。 (unknown)

Expected: 事前学習、インストラクションチューニング、事後学習。

### Retest

対象範囲のLLM学習プロセスとして、最も適切な並びはどれか。

- A. 事前学習で基盤能力を獲得し、インストラクションチューニングで指示応答を学び、事後学習で安全性や有用性を調整する。 (correct)
- B. 入力、思考、感情、会話という人間の学習段階に分けられる。 (M1)
- C. プロンプト、コンテキストウィンドウ、Function CallingがLLMの主な学習段階である。 (M2)
- D. 事前と事後という語があるため、学習前テストと学習後テストだけを指す。 (M3)
- E. わからない。 (unknown)

Expected: 事前学習で基盤能力を獲得し、インストラクションチューニングで指示応答を学び、事後学習で安全性や有用性を調整する。

### L0 Check

LLMの主な学習プロセスを3段階で説明してください。

### Final Test

新しいLLMを作る流れとして、まず大量テキストで基盤能力を作り、次に指示応答を学ばせ、最後に安全性や有用性を調整する。この3段階の説明として最も適切なものはどれか。

- A. 事前学習、インストラクションチューニング、事後学習の順に説明している。 (correct)
- B. 入力、思考、感情、会話という人間の学習段階を説明している。 (M1)
- C. プロンプト、コンテキストウィンドウ、Function Callingの順を説明している。 (M2)
- D. 学習前テスト、学習、学習後テストだけを説明している。 (M3)
- E. わからない。 (unknown)

Expected: 事前学習、インストラクションチューニング、事後学習の順に説明している。

### Transfer

新しいLLMを作る説明資料で、まず大量テキストから基盤能力を作り、その後指示応答と安全性を調整すると書かれている。この流れを3段階に分けて説明してください。
