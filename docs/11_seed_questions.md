# Seed Questions

このファイルは `backend/app/seed/data.py` の現行seedと同期する。現在の対象用語は、教材RAG資産に合わせた5語である。

## 対象用語

1. `transformer`: Transformer
2. `attention`: Attention
3. `llm_training_process`: LLMの学習段階
4. `pretraining`: 事前学習
5. `post_training`: 事後学習

## Questions

## Q1 Transformer

- slug: `transformer`
- description: AttentionレイヤーとFFNレイヤーを重ね、トークン間の関係性とトークンごとの特徴変換を繰り返す構造。
- keywords: Attention, FFN, 関係性, 並列処理

### Pretest

Transformerの構造について、最も適切な説明はどれか。

- A. AttentionレイヤーとFFNレイヤーを重ね、トークン間の関係性とトークンごとの特徴変換を繰り返す構造。 (correct)
- B. Transformerとは、AIが文章全体を人間のように意識して読む能力そのもの。 (M1)
- C. TransformerはRNNと同じで、前の時刻の隠れ状態を順番に渡しながら処理する構造。 (M2)
- D. Transformerは『変換する』という名前なので、単に文章を別の言語へ翻訳する機能のこと。 (M3)
- E. わからない。 (unknown)

Expected: AttentionレイヤーとFFNレイヤーを重ね、トークン間の関係性とトークンごとの特徴変換を繰り返す構造。

### Retest

Transformerの説明として、RNNとの違いも踏まえて最も適切なものはどれか。

- A. AttentionとFFNを組み合わせ、逐次的な隠れ状態の受け渡しだけに頼らず、トークン間の関係性と各トークンの特徴変換を扱う構造。 (correct)
- B. AIが文章全体を人間の意識と同じように理解して読む能力そのもの。 (M1)
- C. RNNと同じく、前の時刻の隠れ状態を順番に渡すことが中心の構造。 (M2)
- D. 名前にTransformerとあるため、文章を別の言語へ変換する翻訳機能だけを指す。 (M3)
- E. わからない。 (unknown)

Expected: AttentionとFFNを組み合わせ、逐次的な隠れ状態の受け渡しだけに頼らず、トークン間の関係性と各トークンの特徴変換を扱う構造。

### L0 Check

Transformerの基本構造を、AttentionとFFNの役割に触れて説明してください。

### Transfer

長い文章の要約モデルで、離れた位置にある語同士の関係を扱う必要がある。この場面でTransformer構造が有効な理由を説明してください。

## Q2 Attention

- slug: `attention`
- description: 入力中のトークン同士の関係の強さを計算し、重要度に応じて情報を重み付けして利用する仕組み。
- keywords: トークン, 関係, 重み付け, 重要度

### Pretest

TransformerにおけるAttentionの役割として、最も適切なものはどれか。

- A. 入力中のトークン同士の関係の強さを計算し、重要度に応じて情報を重み付けして利用する仕組み。 (correct)
- B. AIが人間のように注意や集中を向ける心理的な能力。 (M1)
- C. FFNと同じで、各トークンの特徴量ベクトルを個別に変化させる処理。 (M2)
- D. 文章中に出てくる重要そうな単語だけを探して印を付ける処理。 (M3)
- E. わからない。 (unknown)

Expected: 入力中のトークン同士の関係の強さを計算し、重要度に応じて情報を重み付けして利用する仕組み。

### Retest

Transformer内のAttentionの働きとして、最も適切なものはどれか。

- A. 入力中の各トークンが他のトークンとどの程度関係するかを計算し、その重みに応じて情報を利用する仕組み。 (correct)
- B. AIが人間のように気を散らさず集中する心理的能力。 (M1)
- C. FFNと同じで、各トークンを個別に変換するだけの処理。 (M2)
- D. 重要そうな単語を探して印を付けるだけの処理。 (M3)
- E. わからない。 (unknown)

Expected: 入力中の各トークンが他のトークンとどの程度関係するかを計算し、その重みに応じて情報を利用する仕組み。

### L0 Check

Attentionの役割を、トークン間の関係と重み付けに触れて説明してください。

### Transfer

質問応答モデルが、質問文と本文中の関連箇所を結びつけて回答する場合、Attentionの考え方はどのように関係しますか。

## Q3 LLMの学習段階

- slug: `llm_training_process`
- description: LLMの主な学習プロセスは、事前学習、インストラクションチューニング、事後学習に分けられる。
- keywords: 事前学習, インストラクションチューニング, 事後学習

### Pretest

対象範囲で説明されているLLMの主な学習プロセスの組み合わせとして、最も適切なものはどれか。

- A. 事前学習、インストラクションチューニング、事後学習。 (correct)
- B. 入力、思考、感情、会話という人間の学習段階。 (M1)
- C. プロンプト、コンテキストウィンドウ、Function Calling。 (M2)
- D. 『事前』『事後』という語があるので、学習前と学習後のテストだけを指す。 (M3)
- E. わからない。 (unknown)

Expected: 事前学習、インストラクションチューニング、事後学習。

### Retest

対象範囲のLLM学習プロセスとして、最も適切な並びはどれか。

- A. 事前学習で基盤能力を獲得し、インストラクションチューニングで指示応答を学び、事後学習で安全性や有用性を調整する。 (correct)
- B. 入力、思考、感情、会話という人間の学習段階に分けられる。 (M1)
- C. プロンプト、コンテキストウィンドウ、Function CallingがLLMの主な学習段階である。 (M2)
- D. 事前と事後という語があるため、学習前テストと学習後テストだけを指す。 (M3)
- E. わからない。 (unknown)

Expected: 事前学習で基盤能力を獲得し、インストラクションチューニングで指示応答を学び、事後学習で安全性や有用性を調整する。

### L0 Check

LLMの主な学習プロセスを3段階で説明してください。

### Transfer

新しいLLMを作る説明資料で、まず大量テキストから基盤能力を作り、その後指示応答と安全性を調整すると書かれている。この流れを3段階に分けて説明してください。

## Q4 事前学習

- slug: `pretraining`
- description: 大規模で多様なテキストデータなどから、言語理解・生成能力や一般的知識の基盤を獲得する段階。
- keywords: 大規模, 多様, 次単語予測, 基盤

### Pretest

LLMの事前学習の目的として、最も適切なものはどれか。

- A. 大規模で多様なテキストデータなどから、言語理解・生成能力や一般的知識の基盤を獲得すること。 (correct)
- B. 人間が使う前に、AIに性格や倫理観を教え込む最終調整のこと。 (M1)
- C. インストラクションチューニングと同じで、質問と理想回答のペアだけを学習すること。 (M2)
- D. 事前という言葉があるので、モデルを使う前にユーザが入力する注意書きのこと。 (M3)
- E. わからない。 (unknown)

Expected: 大規模で多様なテキストデータなどから、言語理解・生成能力や一般的知識の基盤を獲得すること。

### Retest

LLMの事前学習で主に行われることとして、最も適切なものはどれか。

- A. 大規模で多様なデータから、言語理解・生成能力や一般的知識の基盤を獲得する。 (correct)
- B. 利用者に出す前に、安全性や価値観だけを最後に調整する。 (M1)
- C. インストラクションチューニングと同じく、質問と理想回答のペアだけを学ぶ。 (M2)
- D. モデルを使う前に、ユーザが入力する注意書きや前置きのこと。 (M3)
- E. わからない。 (unknown)

Expected: 大規模で多様なデータから、言語理解・生成能力や一般的知識の基盤を獲得する。

### L0 Check

LLMの事前学習の目的を、データ規模と獲得する能力に触れて説明してください。

### Transfer

モデルがWebテキスト、コード、数学問題などを大量に使って次に来る語を予測する訓練をしている。この訓練を事前学習として説明してください。

## Q5 事後学習

- slug: `post_training`
- description: LLMの出力を人間の価値観や安全性・有用性に合うよう、人間評価や報酬モデルなどを用いて調整する段階。
- keywords: 人間評価, 報酬モデル, 安全性, 有用性

### Pretest

LLMの事後学習の説明として、最も適切なものはどれか。

- A. LLMの出力を人間の価値観や安全性・有用性により合うよう、人間評価や報酬モデルなどを用いて調整する段階。 (correct)
- B. AIが出力した後に、人間のように反省して感情を整える段階。 (M1)
- C. 事前学習と同じで、Web上の膨大なテキストから次単語予測を学ぶ段階。 (M2)
- D. 事後という語があるので、ユーザへの回答が終わった後にログを保存するだけの処理。 (M3)
- E. わからない。 (unknown)

Expected: LLMの出力を人間の価値観や安全性・有用性により合うよう、人間評価や報酬モデルなどを用いて調整する段階。

### Retest

事後学習の目的として、最も適切なものはどれか。

- A. 人間評価や報酬モデルなどを用いて、出力をより安全で有用なものに近づける。 (correct)
- B. AIが回答後に人間のように反省し、感情を整える段階。 (M1)
- C. 事前学習と同じく、Web上の大量テキストから次単語予測を学ぶ段階。 (M2)
- D. 回答が終わった後に、ログを保存するだけの処理。 (M3)
- E. わからない。 (unknown)

Expected: 人間評価や報酬モデルなどを用いて、出力をより安全で有用なものに近づける。

### L0 Check

LLMの事後学習の目的を、人間評価や安全性・有用性に触れて説明してください。

### Transfer

あるAIアシスタントで、有害な出力を抑え、より丁寧で役に立つ回答になるよう人間評価を使って調整している。この工程を事後学習として説明してください。
