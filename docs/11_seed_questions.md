# 11. Seed Questions

各問題には以下を持たせる。

- correct option
- M1 option
- M2 option
- M3 option
- unknown option

M4は転移問題で検出する。

## Q1 Attention

Transformerにおける「Attention」の説明として、最も適切なものはどれか。

A. 入力中の各単語やトークン同士の関係の強さを計算し、重要度に応じて情報を重み付けして利用する仕組み。  
B. AIが人間のように「注意」や「集中」を向ける仕組み。  
C. AttentionはEmbeddingと同じで、単語を数値ベクトルとして保存するための仕組み。  
D. Attentionとは、文章中に出てくる重要語だけを探し、その単語に印を付ける処理。  
E. わからない。

Labels: A correct / B M1 / C M2 / D M3 / E unknown

Transfer: 画像説明モデルにおいて、画像内の各領域と生成する単語の関係を重み付けしている仕組みを説明するとき、Attentionの考え方はどのように使えるか。

## Q4 過学習

A. モデルが訓練データに適合しすぎて、新しいデータに対する性能が下がる状態。  
B. AIが人間のように勉強しすぎて疲れてしまう状態。  
C. 汎化と同じで、未知のデータにもよく対応できる状態。  
D. 「学習」という言葉があるので、訓練回数が多ければすべて過学習である。  
E. わからない。

Labels: A correct / B M1 / C M2 / D M3 / E unknown

Transfer: チャットボットが、練習用に用意された質問には高精度に答えられるが、少し言い換えた質問にはうまく答えられない。この現象を、過学習または汎化の観点から説明してください。

C. 過学習と同じで、訓練データに完全に一致すること。  
D. 「一般化」という言葉があるので、細かい違いをすべて無視すること。

Labels: A correct / B M1 / C M2 / D M3 / E unknown

B. AIの性格や気分を細かく調整すること。  
C. Prompt engineeringと同じで、入力文の書き方だけを工夫すること。

Labels: A correct / B M1 / C M2 / D M3 / E unknown

## Q7 Prompt

A. モデルに与える入力文や指示文のこと。  
B. AIの内部にある考える力そのもの。  
C. 学習データと同じで、モデルの重みを直接更新する情報。  
D. 「質問文」と書かれている場合だけPromptであり、命令文はPromptではない。  
E. わからない。

Labels: A correct / B M1 / C M2 / D M3 / E unknown

Transfer: 「次の文章を小学生にも分かるように要約してください。ただし200字以内で書いてください」という入力には、質問・命令・制約が含まれている。この入力全体はPromptと呼べるか。理由も説明してください。
