# 11. Seed Questions

各選択式問題には以下を持たせる。

- correct option
- M1 option
- M2 option
- M3 option
- unknown option

M4は主に転移問題で検出する。事前テストではM4選択肢を基本的に置かない。

## 問題作成ルール

- `pretest` と `retest` で同じ問題文を使わない
- `construct_key` は同じでも `variant_key` は分ける
- 選択肢文も可能な範囲で言い換える
- 転移問題は学習時と異なる文脈にする
- 事前テストは理由記述を出さない。再テスト、確認テストでは理由記述を必須にする
- 「わからない」選択肢を必ず入れる

## Seed Terms

1. 過学習
2. 汎化
3. Attention
4. Embedding
6. Fine-tuning
7. Prompt
8. RAG

## Q1 Attention

### Pretest

Transformerにおける「Attention」の説明として、最も適切なものはどれか。

A. 入力中の各単語やトークン同士の関係の強さを計算し、重要度に応じて情報を重み付けして利用する仕組み。
B. AIが人間のように「注意」や「集中」を向ける仕組み。
C. AttentionはEmbeddingと同じで、単語を数値ベクトルとして保存するための仕組み。
D. Attentionとは、文章中に出てくる重要語だけを探し、その単語に印を付ける処理。
E. わからない。

Labels: A correct / B M1 / C M2 / D M3 / E unknown

### Retest Variant

文章を処理するモデルでAttentionが果たす役割として、最も適切なものはどれか。

A. 入力内の要素同士の関係を計算し、必要な情報へ重みを付けて利用する。
B. AIが人間と同じように集中している状態を表す。
C. 単語をベクトルとして保存するEmbeddingと同じ処理である。
D. 文章中の目立つ単語を探して印を付けるだけの処理である。
E. わからない。

Labels: A correct / B M1 / C M2 / D M3 / E unknown

### Transfer

画像説明モデルにおいて、画像内の各領域と生成する単語の関係を重み付けしている仕組みを説明するとき、Attentionの考え方はどのように使えるか。理由も説明してください。

Expected: 文章中の単語だけでなく、画像領域と生成語の対応関係にも重み付けの考え方を適用できる、と説明できる。

## Q2 Embedding

### Pretest

Embeddingの説明として、最も適切なものはどれか。

A. 単語や文などの情報を、意味的な関係を扱いやすい数値ベクトルに変換した表現。
B. AIが知識をしまっておく保存場所そのもの。
C. Attentionと同じで、重要な単語を選び出す仕組み。
D. 「埋め込み」という言葉があるので、データをファイルの中に埋め込む処理。
E. わからない。

Labels: A correct / B M1 / C M2 / D M3 / E unknown

### Retest Variant

自然言語処理でEmbeddingを使う主な理由として、最も適切なものはどれか。

A. 単語や文を数値ベクトルとして表し、意味的な近さを計算しやすくするため。
B. モデル内部に知識を物理的に保管する棚を作るため。
C. Attentionと同じように重要語だけを探すため。
D. ファイルへ文章を埋め込んで保存するため。
E. わからない。

Labels: A correct / B M1 / C M2 / D M3 / E unknown

### Transfer

レコメンドシステムで、ユーザーや商品を数値ベクトルで表し、似たユーザーや商品を探す場合、Embeddingの考え方はどのように使われているか説明してください。

Expected: 単語以外の対象でも、特徴や意味的関係をベクトル空間で扱う表現として使える、と説明できる。

## Q3 Token

### Pretest

Tokenの説明として、最も適切なものはどれか。

A. AIが理解した意味そのもの。
B. 入力文をモデルが処理しやすい単位に分割したもの。単語、文字、単語の一部などが含まれる。
C. Embeddingと同じで、単語を数値ベクトルにしたもの。
D. 「token」は短い記号なので、短い単語だけを指す。
E. わからない。

Labels: B correct / A M1 / C M2 / D M3 / E unknown

### Retest Variant

大規模言語モデルに文章を入力するときのTokenについて、最も適切な説明はどれか。

A. モデルが理解した意味内容そのもの。
B. 文章を処理するために分けた単位で、単語全体とは限らない。
C. Embeddingと同じ意味で、ベクトル表現そのもの。
D. 短い英単語だけをTokenと呼ぶ。
E. わからない。

Labels: B correct / A M1 / C M2 / D M3 / E unknown

### Transfer

日本語の文章「東京都に行く」が、モデル内部で文字や単語の一部に分割される場合がある。このときTokenという考え方を使って何が説明できるか、理由も含めて説明してください。

Expected: Tokenは処理単位であり、単語そのものや意味そのものとは限らない、と説明できる。

## Q4 過学習

### Pretest

過学習の説明として、最も適切なものはどれか。

A. モデルが訓練データに適合しすぎて、新しいデータに対する性能が下がる状態。
B. AIが人間のように勉強しすぎて疲れてしまう状態。
C. 汎化と同じで、未知のデータにもよく対応できる状態。
D. 「学習」という言葉があるので、訓練回数が多ければすべて過学習である。
E. わからない。

Labels: A correct / B M1 / C M2 / D M3 / E unknown

### Retest Variant

訓練データでは高い精度だが、未知データでは精度が大きく下がるモデルについて、最も適切な説明はどれか。

A. 訓練データに合わせすぎて、未知データへの対応が弱くなっている。
B. AIが学習しすぎて疲れている。
C. 汎化が十分にできている状態である。
D. 訓練という言葉があるので、訓練した時点ですべて過学習である。
E. わからない。

Labels: A correct / B M1 / C M2 / D M3 / E unknown

### Transfer

チャットボットが、練習用に用意された質問には高精度に答えられるが、少し言い換えた質問にはうまく答えられない。この現象を、過学習または汎化の観点から説明してください。

Expected: 練習質問に過度に適合し、言い換えという未知入力へ汎化できていない、と説明できる。

## Q5 汎化

### Pretest

汎化の説明として、最も適切なものはどれか。

A. 学習した内容を、訓練データだけでなく未知のデータにも適切に適用できること。
B. AIが物事を人間のように一般常識として理解すること。
C. 過学習と同じで、訓練データに完全に一致すること。
D. 「一般化」という言葉があるので、細かい違いをすべて無視すること。
E. わからない。

Labels: A correct / B M1 / C M2 / D M3 / E unknown

### Retest Variant

機械学習における汎化として、最も適切な説明はどれか。

A. 訓練で見ていないデータにも、学習した規則を適切に使えること。
B. AIが人間の常識をすべて身につけること。
C. 過学習と同じで、訓練データに完全一致すること。
D. 違いを無視して何でも同じ扱いにすること。
E. わからない。

Labels: A correct / B M1 / C M2 / D M3 / E unknown

### Transfer

迷惑メール分類器が、学習に使っていない新しい文面の迷惑メールも検出できた。この結果を汎化の観点から説明してください。

Expected: 訓練データだけでなく未知の文面にも学習した特徴を適用できている、と説明できる。

## Q6 Fine-tuning

### Pretest

Fine-tuningの説明として、最も適切なものはどれか。

A. 既に学習済みのモデルを、特定の目的やデータに合わせて追加学習させること。
B. AIの性格や気分を細かく調整すること。
C. Prompt engineeringと同じで、入力文の書き方だけを工夫すること。
D. 「fine」という言葉があるので、モデルの出力をきれいな文章に直すこと。
E. わからない。

Labels: A correct / B M1 / C M2 / D M3 / E unknown

### Retest Variant

Fine-tuningの目的として、最も適切なものはどれか。

A. 学習済みモデルを特定タスクやデータに合わせて追加で調整すること。
B. AIの気分や性格を人間のように変えること。
C. Promptの書き方だけを変えること。
D. 出力文をきれいに整えること。
E. わからない。

Labels: A correct / B M1 / C M2 / D M3 / E unknown

### Transfer

医療文書分類に強いモデルを作るため、一般的な事前学習済みモデルに医療文書データを追加学習させる。この操作をFine-tuningとして説明できるか。理由も説明してください。

Expected: 既存モデルを特定領域のデータで追加学習させるためFine-tuningと説明できる。

## Q7 Prompt

### Pretest

Promptの説明として、最も適切なものはどれか。

A. モデルに与える入力文や指示文のこと。
B. AIの内部にある考える力そのもの。
C. 学習データと同じで、モデルの重みを直接更新する情報。
D. 「質問文」と書かれている場合だけPromptであり、命令文はPromptではない。
E. わからない。

Labels: A correct / B M1 / C M2 / D M3 / E unknown

### Retest Variant

生成AIにおけるPromptとして、最も適切な説明はどれか。

A. モデルに入力する指示、質問、条件などを含む文。
B. AIの内部で考える力そのもの。
C. モデルの重みを直接更新する学習データ。
D. 疑問符がある質問文だけを指す。
E. わからない。

Labels: A correct / B M1 / C M2 / D M3 / E unknown

### Transfer

「次の文章を小学生にも分かるように要約してください。ただし200字以内で書いてください」という入力には、質問・命令・制約が含まれている。この入力全体はPromptと呼べるか。理由も説明してください。

Expected: 質問文だけでなく、命令や制約を含むモデルへの入力全体がPromptである、と説明できる。

## Q8 RAG

### Pretest

RAGの説明として、最も適切なものはどれか。

A. モデルが外部文書などを検索し、その情報を使って回答を生成する仕組み。
B. AIの中に巨大な図書館が物理的に保存されている状態。
C. Fine-tuningと同じで、外部文書を使ってモデルの重みを直接更新すること。
D. 「検索」という言葉があるので、検索結果をそのままコピーして返すだけの仕組み。
E. わからない。

Labels: A correct / B M1 / C M2 / D M3 / E unknown

### Retest Variant

RAGの特徴として、最も適切なものはどれか。

A. 外部情報を検索し、その内容を参照して回答生成を行う。
B. モデル内部に物理的な図書館を持つ。
C. Fine-tuningと同じく、検索した文書で重みを直接更新する。
D. 検索結果を必ずそのままコピーして返すだけである。
E. わからない。

Labels: A correct / B M1 / C M2 / D M3 / E unknown

### Transfer

社内FAQを参照して回答するAIチャットを作るとき、回答前に関連文書を検索し、その内容をもとに回答を生成する仕組みをRAGとして説明できるか。理由も説明してください。

Expected: 外部文書検索と生成を組み合わせているためRAGである、と説明できる。Fine-tuningのように重みを直接更新するわけではない点に触れられるとなおよい。

## Learning Practice Examples

学習セッションでは、上記のpretest/retest文面をそのまま使わず、短い類題を使う。

例:

| term | practice question | expected |
|---|---|---|
| overfitting | 訓練データでは良いがテストデータでは悪い場合、何を疑うか。 | 過学習 |
| prompt | 「箇条書きで3点にまとめて」はPromptに含まれるか。 | 含まれる |
| rag | 外部文書を検索してから回答することと、モデルを追加学習することの違いは何か。 | RAGとFine-tuningの違い |

## Optional Additional Terms

追加候補はMVP後にseedへ追加する。

### Loss

Correct: モデルの予測と正解とのずれを数値化したもの。
M1: AIが失敗して自信をなくした状態。
M2: Accuracyと同じで、正解率の高さを表す指標。
M3: お金やデータが失われた量。

### ハルシネーション

Correct: AIが存在しない事実や根拠のない内容を、もっともらしく生成してしまうこと。
M1: AIが人間のように幻覚を見ている状態。
M2: バイアスと同じで、特定集団に対して不公平な出力をすること。
M3: 画像生成AIだけで起こる現象。

### 正則化

Correct: モデルが訓練データに過度に適合しすぎないように、複雑さを抑えるための工夫。
M1: AIの答えを社会的に正しいものに直すこと。
M2: 正規化と同じで、データの値の範囲をそろえる処理。
M3: 間違った出力を正解に修正する処理。
