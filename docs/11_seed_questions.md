# 11. Seed Questions

このファイルは `backend/app/seed/data.py` と `backend/app/seed/seed_questions.py` の現行seed仕様を説明する。

## 現行対象用語

現行MVPのactive対象は2語である。

| slug | label | keywords |
|---|---|---|
| `llm_training_process` | LLMの学習段階 | 事前学習, インストラクションチューニング, 事後学習 |
| `transformer` | Transformer | Attention, FFN, トークン, 関係性 |

過去仕様の追加用語は、現行MVPでは非activeまたは将来拡張候補として扱う。

## 同一問題運用

2026-06-22時点のユーザー指定により、L2概念理解問題・再テスト・最終テストでは、同じ用語について同一の問題文と選択肢セットを使う。

- seed投入時は `questions.pretest` を基準にする
- `retest` は `pretest` と同じ本文・選択肢を保存する
- `final_test` も `pretest` と同じ本文・選択肢を保存する
- 学習セッションの `concept_understanding` 問題も同じ本文・選択肢セットを使う
- 過去にあった別文面案は旧仕様または将来の問題バリアント候補とする

## LLMの学習段階

### Pretest / Retest / Final Test / L2 Concept

対象範囲で説明されているLLMの主な学習プロセスの組み合わせとして、最も適切なものはどれか。

- A. 大量のテキストで言語パターンを学ぶ事前学習、指示に従う応答へ調整するインストラクションチューニング、出力の望ましさを高める事後学習。 (correct)
- B. 入力された文章を理解する事前学習、内部で思考するインストラクションチューニング、必要に応じて意図を形成してから会話として出力する事後学習。 (M1)
- C. ユーザーがプロンプトを入力する事前学習、コンテキストウィンドウに情報を保持するインストラクションチューニング、必要に応じてFunction Callingで外部処理を行う事後学習。 (M2)
- D. 学習前の性能を測定する事前学習、学習後の性能をテストするインストラクションチューニング、前後比較を行う評価手順である事後学習。 (M3)
- E. わからない。 (unknown)

Expected: 大量のテキストで言語パターンを学ぶ事前学習、指示に従う応答へ調整するインストラクションチューニング、出力の望ましさを高める事後学習。

### L0 Check

LLMの主な学習プロセスを3段階で説明してください。

### Transfer Extension

新しいLLMを作る説明資料で、まず大量テキストから基盤能力を作り、その後指示応答と安全性を調整すると書かれている。この流れを3段階に分けて説明してください。

## Transformer

### Pretest / Retest / Final Test / L2 Concept

Transformerの構造の説明として、最も適切なものはどれか。

- A. Attentionレイヤーでトークン間の関係性を扱い、FFNレイヤーで各トークンの特徴を変換する構造。 (correct)
- B. Attentionレイヤーが文章全体の意味を理解し、FFNレイヤーが思考して判断を行う構造。 (M1)
- C. 入力文を先頭から順番に処理し、前の単語の隠れ状態を次の単語へ渡しながら文脈を保持する構造。 (M2)
- D. Attentionレイヤーで単語の意味を検索し、FFNレイヤーで正しい単語に置き換える構造。 (M3)
- E. わからない。 (unknown)

Expected: Attentionレイヤーでトークン間の関係性を扱い、FFNレイヤーで各トークンの特徴を変換する構造。

### L0 Check

Transformerの構造を、Attentionレイヤー、FFNレイヤー、トークン間の関係性に触れて説明してください。

### Transfer Extension

長い文章の要約で、離れた語同士の関係を扱いながら各トークンの特徴を変換できる理由を、Transformerの構造から説明してください。
