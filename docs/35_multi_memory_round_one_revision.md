ラベルはデバッグ配置の内部ラベル。ランダム配置でも同じ内部選択肢と判定に対応する。

## 分類理由と解釈の範囲

- マルチエージェントG：資料から指定情報を取り出して返す検索機能を、それを使って作業を行うAIエージェントと同じ種類の主体として数えている。情報を渡すことだけを、独立したエージェントである根拠とする点を対象にする。エージェントを内部に含むあらゆるツールを一律に否定する主張ではない。
- 記憶F：保存した希望を今回の入力として渡して回答できたことから、次回の相談でも記録参照なしに保持されると判断している。今回の回答成功だけでは、別の日の新しい相談で記録を利用できる仕組みが備わることを示さない。新版には重み更新の記述がないため、その主張を補って説明しない。
- 記憶H：同じ会話内で履歴が利用されることと、別の日の新しい会話でも個人の希望を保持する長期記憶を同じ仕組みとして分類している。保存済み履歴を入力へ戻す設計自体や、実際に会話間の保存を実装したシステムを否定するものではない。

判定は本研究の操作的な割当としてM1/M3を維持する。Chiの理論がこの選択肢の分類を直接実証したわけではなく、機械検査・Mockの成功を分類妥当性、初心者への読みやすさ、問題間の難易度同等性の実証とは扱わない。マルチエージェントV1の先頭Dに残る曖昧さも[採用時記録](27_multi_agent_choice_revision.md)のまま保持する。
