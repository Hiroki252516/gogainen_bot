# Frontend UX Flow

テスト画面は `selection_mode = multiple` の場合、チェックボックスで選択肢を表示する。`min_selections = max_selections = 3` のため、3つ選ばないと送信できない。

被験者向け学習画面の段階表示は次の3つだけを使う。

- 豊富化
- 概念変化
- 教材フィードバック

旧ステージ名 `term_understanding` / `concept_understanding` は被験者向け表示に使わない。管理画面・CSVの回答履歴では、複数選択回答を `A / B / C` のように表示する。

教材本文やフィードバック本文にはM1/M3などの内部ラベルを直接出さない。
