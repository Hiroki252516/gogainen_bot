# 09. Frontend UX Flow

## Pages

### /admin

管理者画面。

- 被験者一覧
- 実験進捗
- CSV出力
- Codex app-server接続状態
- AI診断失敗ログ

### /start

被験者開始画面。

- 説明
- 同意チェック
- group condition選択またはランダム割当
- 開始ボタン

### /survey/pre

事前アンケート。

### /pretest

事前テスト。

1問ずつ表示する。

各問:

- 問題文
- 選択肢
- 理由記述欄
- 自信度 1〜5
- 次へ

### /diagnosing

AI診断中画面。

### /learning-targets

学習対象一覧。

被験者にはM1〜M4を直接表示しない。

表示例:

```text
今回重点的に確認する内容

1. Attention: 人間の注意ではなく、モデル内部の重み付けとして理解する
2. RAG: Fine-tuningとの違いを確認する
```

### /learning/[termSlug]

1用語の学習画面。

画面構成:

```text
┌──────────────────────────────┐
│ 対象用語・前回回答             │
├──────────────┬───────────────┤
│ AIミニ教材     │ AIチューター対話  │
├──────────────┴───────────────┤
│ 回答欄・自己説明欄             │
├──────────────────────────────┤
│ 自信度・次へ                   │
└──────────────────────────────┘
```

チャット制御ボタン:

- もう少し簡単に
- 例を見たい
- 反例を見たい
- 違いを比較したい
- 自分の説明を確認して

禁止:

- 答えだけ教えて
- テスト問題の正解を教えて
- 次の問題を解いて

禁止要求への返答:

```text
この実験では、正解だけを提示することはできません。
代わりに、考えるための観点を1つ示します。
```

### /retest

即時再テスト。

- チャット不可
- ヒント不可
- 結果は即時表示しない

### /l0-check

L0確認。

- ヒントなし
- 解説なし
- チャット欄なし
- 自由記述中心

### /transfer-test

転移テスト。

- ヒントなし
- チャット欄なし
- 別文脈問題
- 理由記述必須

### /survey/post

主観評価。

### /finish

終了画面。
