## 用語の補足

テスト（内部final_testを含む）と回答後解説には共通辞書の注釈を表示する。幅1100px以上ではテスト本文の右側に追従する欄、幅1100px未満ではボタンで開閉するパネルに表示し、回答後解説の注釈は解説の下に表示する。テストでは問題文・全選択肢・用語見出しから抽出し、回答前から同じ一覧を利用できる。新規参加者の教材は教材内解説モードのため右側注釈欄を表示しない。空配列・保存値欠落時は欄やボタンを出さず、確認問題自体には表示しない。注釈内容・保存方式は両群共通とする。[24](24_learning_glossary.md)。

## 現行の画面要件

参加者画面では、事前テストから終了まで、ヘッダー直下に実験全体の工程進捗メーターを表示する。メーターは横長バー、工程名、％で構成し、事前テスト0％、事前後1回目まで25％、事前後2回目まで50％、アンケート75％、終了100％とする。これは工程の進み具合であり、回答数・理解度・得点ではない。100％も実験手続きの完了を示し、満点到達を意味しない。

現行仕様版47では事前満点者のみ、結果表示snapshotがONなら結果確認画面を経てsurveyへ進み、OFFなら直接surveyへ進む。それ以外の事前結果および再テストの全体結果確認画面は従来どおり省略する。結果画面を通る事前満点者はsurveyを次工程として表示する。既存のテスト問題番号、用語ごとの学習進捗、残り挑戦回数は維持する。

進捗は `current-step` の読み取り専用応答から取得し、定期ポーリングやブラウザー内カウンターは使わない。読み込み中は割合を表示せず、取得失敗時は再取得ボタンを出すが、回答や画面操作を止めない。旧試用・対応する進捗がない場合は表示しない。進捗バーは読み上げ可能にする。

2026-10-21追加: /consentにはユーザー提示の同意書全文・必須の学籍番号・同意チェックを表示する。学籍番号欄は半角数字1〜64桁だけを受け付け、入力・貼り付け時にそれ以外を除去し、送信時も検証する。責任者・保存場所・保管期間は保留中のため動作確認用と明示するが、ユーザー指定により新規登録を可能とする。管理画面には対応表の表示・CSV取得・個別/全件削除を追加する。削除は確認ポップアップを経由し、対応表だけの削除と研究データの削除を区別する。当時は管理者認証を追加していなかった。2026-10-27に管理画面の伏せ字パスワード入力ポップアップ（既定abc）を追加し、認証成功後にだけ管理画面を表示・データ取得する。キャンセルは/startへ戻り、再入場・再読込は再入力、ロックはサーバーのセッションも失効させる。[管理APIの保護](15_security_privacy.md)。

教材内の###小見出しは両群ともAIが生成する。文言・数・順序・まとめ方を画面で固定せず、生成Markdownをそのまま描画する。冒頭の##用語名、画面側の教材/問題ラベル、回答後解説の見出しは維持する。章立て監査と必須証拠の内部JSONは参加者へ表示しない。

管理画面は旧試用を明記して現行群集計から除外し、再計算と削除を無効化する。現行参加者数と旧試用数を別々に表示し、全体の評価サマリーは現行参加者だけを対象とする。過去の保存済み評価は個別ログから閲覧でき、回答履歴には試用区分を表示する。過去値は履歴用表示に隔離する。

AI設定欄ではGPT-6.1 Sol / GPT-6 Luna / GPT-6 Astra、推論レベルlow/medium/high/xhigh/max、および初期OFFのCodex Fast modeを切り替えられる。AI設定のいずれかの更新中は他のAI設定操作を無効化する。Fast modeはMockでは切替不可とし、対応モデル・アカウントに依存すること、使用量が増えること、速度向上幅が一定でないことを表示する。管理上書きはbackend内だけに保持され、次回のAI呼び出しから適用する。Fast modeはbackend再起動でOFFへ戻る。実験中の切替は同一参加者内のモデル・利用条件が混在し得るため、実験開始前に固定する。

管理画面の選択肢配置設定で「デバッグ配置」と「ランダム配置」を切り替える。モード設定はDBに保存され、新規参加者の開始時に固定される。ランダム配置では「わからない」を最後のJに固定し、残る9択をA〜Iへ並べ替えることを管理画面にも表示する。単独選択の処理は表示ラベルではなくexclusiveを使い続け、以前の並びで保存された学習問題も再表示・採点できる。保存済みsnapshotは変更しない。デバッグ配置は正解位置の手掛かりとなるため、デバッグ時だけ使用し、実験データ収集前にランダム配置を選ぶ。管理画面の既存アクセス制御は本設定追加では変更しない。

## 問題モード別の現行画面

新規参加者向けの問題モードは管理画面で選択し、RuntimeSetting未設定時の既定値は4用語版とする。保存済みの管理設定は変更しない。登録時に参加者へ固定し、登録後の管理設定変更は既存参加者へ遡及しない。仮説集計・群比較はモードごとに分離する。旧参加者は当時の問題バンクと保存済みsnapshotで結果を復元する。
