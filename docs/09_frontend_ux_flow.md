# Frontend UX Flow

## テスト画面

pretest、retest、final-testは新しい3用語を表示する。固定問題は10択複数選択で、A〜Iから3つ、またはJ「わからない」だけを選ぶ。Jと他の選択肢を同時選択できないようにし、テスト中は正誤・ヒント・解説を表示しない。

retestとlearning確認問題は、同じ問題文をそのまま繰り返さないためにYAMLのvariant_keyを順番に使う。上限後は指定された最後のバリアントを再利用する。

## 学習画面

学習画面は対象概念、学習段階、教材、確認問題、回答結果を表示する。教材はAIが生成した本文を表示するが、M1〜M4、unknown、教授方略、RAGの内部情報は被験者画面へ出さない。

学習本文とフィードバックは段落・箇条書き・見出しを保持できる表示にし、内部ログ用の分類値をUIへ混ぜない。controlとproposedの差は被験者に表示せず、backendのAI call logで検証する。

旧用語Transformerの新規導線は作らないが、過去URL・DBログの互換性は維持する。
