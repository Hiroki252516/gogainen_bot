# 現行設計

新規参加者に仕様版1を保存し、書込みは共通/サービスguardを通す。冪等キャッシュ再送やworker開始より前に旧試用を拒否する。

出題はテスト21問、学習確認v2の30問。固定採点を維持し、AIは教材・正答要約・誤答解説だけ。final_testから学習へ進むには先に採点しlearning_targetsへ遷移する。

教材生成は群別allowlist、共通RAG、backend方略、厳密Schema。proposedだけにtaxonomy/診断/履歴を渡し、必須教授と教材内適用を検証する。最大3試行後は503。

回答後は固定採点とAI解説を記録し、不正解時の次教材を先行生成する。回答確定と公開の境界、二重送信、未利用生成物の負担除外を維持する。

旧列はlegacy_*として残し、既存試用はNULL版のまま読取り専用。画面は表示状態だけを変換し保存状態を変更しない。旧ログ/評価はlegacy_fieldsを含めて参照できるが再計算しない。

隔離DBで移行・seed、実AIでブラウザ確認。モデル/推論、600〜800文字、採点式、問題本文、デバッグ位置は変えない。
