# 目標と現行実装の境界

目標は実験計画書に沿う仕様書、現行挙動はコード・YAML・入力型・テストで確認する。[D01〜D07とQ01〜Q10](20_experiment_plan_alignment.md) を解消する際の実装は別途依頼を必要とする。文書更新だけでAPI・DB・Schema・設定・実行版を切り替えない。

## 目標への変更の進め方

共通/統制群の指示、unknownの教授内容、low推論設定、新アンケート、6仮説の評価対応を、独立した未対応事項として扱う。未確定の集計・新証拠項目・割付方法を実装者が埋めない。変更時には入力・Schema・検査・Mock・保存・CSVの対応範囲と、仕様版切替を改めて決める。

## 現行版3の設計

新規参加者だけ版3を保存し、NULL/版1/2/未対応版は再送やworker開始より前に拒否する。起動時補修も現行版だけ。既存記録を版3へ付け替えず、旧ログ・保存評価を閲覧専用とする。

出題はテスト21問・学習確認v2の30問。固定採点を維持し、AIは教材・正答要約・誤答解説だけ。final_testから学習へ進むには採点とlearning_targetsへの遷移が必要。

3AIタスクに共通用語・構成要素・RAG・interaction_historyを渡し、実験群だけに診断・修正対象・taxonomy・指針を加える。出題の診断連動は両群共通だが、統制群LLMへ分類・診断由来段階を送らない。

教材は600〜800文字で章立ては自由。本文証拠・指定方略・構造等を検査し、最大3試行後は503。証拠を自動補正せずMockへ切り替えない。機械検査は意味の正しさを保証しない。

回答後は固定採点とAI解説を記録し、不正解時の次教材を先行生成する。確定回答を投影するが解説全文を次教材へ入れない。回答成功後だけ公開し、失敗・二重送信・未利用生成物を扱う。

旧列はlegacy_*に隔離し、物理削除・旧値更新・再計算をしない。既存CSVヘッダを保持する。今回の文書整合ではDB移行・seed再同期・実AI呼出しを実行しない。
