# 現行設計

新規参加者に仕様版3を保存し、書込みは共通/サービスguardを通す。NULL/版1/2/未対応版は冪等キャッシュ再送やworker開始より前に拒否する。起動時補修も現行版定数に限定する。

出題はテスト21問、学習確認v2の30問。固定採点を維持し、AIは教材・正答要約・誤答解説だけ。final_testから学習へ進むには先に採点しlearning_targetsへ遷移する。

AIの3タスクに共通用語/構成要素/RAG/interaction_historyを渡し、proposedにだけtaxonomy/診断/修正対象/教授方針を追加する。履歴は全フェーズの採点済み観察記録で、診断やAI解説を含めない。方略と厳密Schema、実験群の必須教授と教材内適用を維持し、最大3試行後は503。両群の確認問題は共通の診断連動規則で選ぶ。

回答後は固定採点とAI解説を記録し、不正解時の次教材を先行生成する。回答確定と公開の境界、二重送信、未利用生成物の負担除外を維持する。

旧列はlegacy_*として残し、既存試用のNULL/版1/2を付け替えず読取り専用にする。画面は表示状態だけを変換し保存状態を変更しない。旧ログ/評価はlegacy_fieldsを含めて参照できるが再計算しない。

章立ては両群ともAI生成。material_structureがCommonMarkを解析し、冒頭##用語名・非空###節と証拠の本文出現を検証する。固定小見出しや自動証拠補正を使わず、必須教授要素を自由な節構成に配置する。見出し・順序・節数・証拠配置は既存JSONに監査する。Mockは決定論的な用語/タイプ別の複数要素をまとめた教材を返す。

隔離DBで移行・seed、実AIでブラウザ確認。モデル/推論、600〜800文字、採点式、問題本文、デバッグ位置は変えない。
