> 履歴資料（2026-10-30以降は実行停止）: ここに記載する易しい版は新規参加者へ出題しない。既存参加者は閲覧専用で群集計・仮説CSVから除外する。問題本文・分類・YAML・問題ID・snapshotと既存記録は履歴復元用に保持し、削除・書換えしない。現在の運用は[22](22_question_set_modes.md)を参照。

この資料は研究者向けで、正解・M分類を含む。参加者画面には表示しない。正本は `backend/app/seed/content/easy/learning_content_easy.yml` と `backend/app/seed/content/easy/learning_questions_v4_easy.yml`。運用・版・解釈の範囲は[22](22_question_set_modes.md)を参照する。

分類は本研究の操作的設計である。M1は働き・条件・結果に関する個別の誤った主張、M3は処理・データ・判断主体などの種類の取り違えを狙う。単なる用語の言い違いと分類する可能性を含み、Chiの理論に照らした妥当性・初心者への読みやすさ・版間の難易度同等性を実証したものではない。RAGは記憶管理を支援でき、同じモデルを複数担当に使うこともできるため、これらを一律に禁止する選択肢として解釈しない。

ラベルはデバッグ配置を示す。ランダム配置ではA〜Iの表示が変わる。J「わからない。」は全問共通。

### 事前テストの教授対象・訂正情報

- D: 正しい説明「資料を一度読ませるだけでは、AI自体が追加学習されたことにはならない。」
  理由・仕組み「質問で渡した資料はその回答の材料であり、別の会話にも自動で覚えているとは限らない。」
  対比例「毎回メモを見て答える方法と、事例を使ってAI自体を訓練する方法を比べる。」
- E: 正しい説明「回答例を質問に添えることと、その例でAIを追加訓練することは別の操作である。」
  理由・仕組み「例を見ながら答える場合はその質問の入力を使っており、学習用データでの訓練は行っていない。」
  対比例「質問に回答の見本を添える方法と、見本を学習用データにして訓練する方法を比べる。」
- F: 正しい説明「指示を書き直すだけでは、AI自体の学習内容を変更する訓練にはならない。」
  理由・仕組み「指示は今回どう答えてほしいかを伝えるもので、モデルの内部を調整する追加学習とは処理が異なる。」
  対比例「短く答えるよう頼む操作と、確認済みの回答例でモデルを追加学習する操作を比べる。」
- G: 正しい説明「RAGに回答例を登録するだけでは、モデルの追加学習は終わらない。」
  理由・仕組み「RAGは必要な情報を探して回答に使う仕組みであり、AI自体の学習内容を変える訓練ではない。」
  対比例「回答例を探して読むことと、回答例でモデル自体を訓練することを比べる。」
  分類境界「資料を登録する検索の準備を、モデルの訓練として扱うこと → 外の情報を探して、その回答で参照する仕組み」。基準「回答時に資料を使う処理か、モデル自体を訓練する処理かで区別する。」
- H: 正しい説明「資料を探すには検索を使い、ファインチューニングは回答例による追加学習に使う。」
  理由・仕組み「ファインチューニングはモデルを訓練する処理であり、質問に関係する案内文を取り出す検索ではない。」
  対比例「案内文を探して質問へ添える操作と、事例で答え方を訓練する操作を比べる。」
  分類境界「訓練の仕組みを、必要な資料を取り出す検索として扱うこと → データを使ってモデル自体を調整する追加学習」。基準「資料を取り出す処理か、モデルを訓練する処理かで区別する。」
- I: 正しい説明「プロンプトへ資料名を書くことだけでは、資料の本文を保存して検索する機能は備わらない。」
  理由・仕組み「プロンプトはAIへ渡す指示や情報であり、名前を書くだけで外のファイルを読める仕組みではない。」
  対比例「資料名を指示へ書くだけの場合と、本文の保存先と検索機能を用意する場合を比べる。」
  分類境界「指示文を、資料本文の保存先や検索機構として扱うこと → AIに渡す指示や、その回答で使う情報」。基準「指示を書いた文面か、本文を保管して取り出す仕組みかで区別する。」

  対比例「一般の趣味の記事を読む場合と、前の相談で聞いた好きなことを記録して読む場合を比べる。」
  分類境界「一般資料だけの検索を、利用者固有の経験の記憶管理として扱うこと → 一般的な外部資料を探して読む処理」。基準「検索方法の名前でなく、個人の情報を保存して変更時に直せるかで区別する。」
- I: 正しい説明「今回だけ前の文を貼る操作と、終了後も続く保存・読み出し・更新の機能は別である。」
  理由・仕組み「入力に書いた内容が別の相談にも残るとは限らない。保存した履歴を入力へ戻すことは記憶の利用になり得る。」
  対比例「その場の質問にだけ好みを書く場合と、保存した好みを次回に探して更新する場合を比べる。」
  分類境界「今回だけの入力追加を、継続的な記憶管理の仕組みとして扱うこと → その回答で使う入力情報の追加」。基準「今だけの入力か、会話をまたぐ保存先や更新の手順があるかで区別する。」
