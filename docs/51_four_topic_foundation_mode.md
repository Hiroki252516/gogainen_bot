# 4用語版テスト問題モード（導入時仕様版44・現行仕様版45）

## 現行条件（仕様版45）

仕様版45 / `experiment-plan-2026-11-09-four-topic-two-retest-rounds-v1`では、4用語版のみ「事前テスト → 学習 → 再テスト1 → 学習 → 再テスト2 → アンケート」の固定フローを適用する。事前テスト満点でも4用語すべてを学習対象とし、再テスト1満点でも同様に全4用語を学習して再テスト2へ進む。誤答がある回は従来どおり誤答用語だけを学習対象にする。再テスト2は満点・未達を問わず採点後にアンケートへ進み、3回目の事前後テストと内部`final_test`は使わない。学習対象がない満点回でも通常の教材・確認問題セッションを用いる。他の問題モードの満点時早期終了は変更しない。

仕様版44以下は閲覧専用とし、保存済み問題・回答・教材・snapshotを変更しない。仕様版44の記録は当時の`test_content_mode`に基づいて問題を復元する。

## 導入時条件（仕様版44・履歴）

仕様版44 / `experiment-plan-2026-11-09-four-topic-foundation-v1`で追加した新規参加者向けの第3モードである。管理画面の「テスト問題モード」では従来の「現行版（場面応用）」「基礎理解版」を維持し、「4用語版」を選べる。既定値は現行版であり、選択値は登録時に`Participant.test_content_mode`へsnapshotする。登録済み参加者には遡及しない。

対象用語と順序は`Transformer` (`transformer`)、`LLMの学習段階` (`llm_training_stages`)、`マルチエージェント` (`multi_agent_four_topic`)、`記憶プロセス` (`memory_process_four_topic`)である。従来2モードの3用語セットや保存済みParticipantの対象用語・回答は変更しない。

## 問題・確認問題

問題の正本は`backend/app/seed/content/standard/four_topic_fundamentals_v1.yml`。添付された第1〜4問の参加者向け設問文・選択肢本文を使用し、各問10択とする。内部役割はA〜Cが正解、D〜FがM1、G〜IがM3、Jがunknown。参加者には役割・分類理由・訂正対象を送らない。

仕様版44では事前テスト、再テスト1・2、内部`final_test`で各用語の同一問題・選択肢を使用し、`final_test`は再テスト1相当だった。各問は正解A〜Cの3つを選択するか、J「わからない」のみを選ぶ。Jと他選択肢の併用、3つ未満・超過、未回答は受け付けない。ランダム配置ではJを最後に固定し、他の9択を決定的に再配置する。表示順は問題snapshotに保存する。仕様版45でも問題内容・配置・採点は変更しないが、4用語版では内部`final_test`を実行しない。

学習確認は直前テストで不正解だった問題がある場合、その保存済み本文・選択肢snapshotを再利用する。問題と選択肢は再テストと共通だが、学習確認の回答はテスト回答とは別に保存・採点する。満点後の固定学習では通常の学習確認セッションを使う。確認問題でも3つ選択またはJ単独の複数選択UIを使う。既存2モードの単一選択・グループ確認動作は変えない。

テスト回答後の同一画面確認では、選択した選択肢ごとの正誤を色とラベルで示し、設問全体の正誤も別に表示する。未選択肢の正誤は表示しない。回答前の出題データには個別正誤を含めない。この表示は保存済み回答を持つ進行中の参加者にも適用する。

## 学習・教材

学習対象と進行順は登録時の4用語カタログに従う。誤答があるテスト回では誤答問題に対応する用語だけを診断・学習対象にする。満点で誤答対象がない事前テスト後または再テスト1後は、固定フローを満たすため4用語すべてを学習対象にし、通常の教材・確認セッションを行う。問題内のM1/M3/unknownの固定分類と既存の両群教授方針を使い、採点・診断を生成AIへ委ねない。

Transformerの教材検索は`rag_ready_教材`の節`1.1.2.4`を、LLMの学習段階は同資料の節`1.1.3.2`を検索対象に指定する。残り2用語の検索条件は各用語の設定に従う。既存3用語モードのRAG検索先、教材生成prompt、教授契約は変更しない。検索indexが利用できない場合も新モード用の対象節を監査情報に保持し、別資料へ黙って切り替えない。

## 事前アンケート・集計

4用語版では`presurvey-four-topic-baseline-v1`を使う。4用語それぞれの事前知識を「知らない」「聞いたことがある」「意味を知っている」「説明できる」の4択で取得し、普段のAI利用頻度・AIを使いこなせているかの自己評価も取得する。既存2モードの事前アンケート版と保存回答は変更しない。事後アンケートは現行のシステム評価・教材評価・任意自由記述を使い、教材評価の仮説指標は事後phaseだけを参照する。

6仮説、参加者ログ、CSV/XLSXは`test_content_mode`を識別し、4用語版は対象4問・4用語を分母として独立集計する。異なるモードを合算しない。既存指標の式は維持し、4問条件の完答・正答率・満点到達は4用語を基準にする。

## 互換性・研究上の注意

問題ID・construct key・問題バンク`split-actions-four-topic-v1`は既存モードと独立している。旧回答は保存時の問題・選択肢snapshotを優先する。起動時seed補修は現行仕様版とprotocolに限定し、仕様43以下の既存記録・問題・回答・教材・snapshot・評価は変更しない。仕様43以下と旧protocolは閲覧専用である。

同じ問題を事前・再テスト・確認で繰り返すため、練習効果が生じる可能性がある。現行版・基礎理解版との難易度や測定特性、回次間の同等性は実証済みではない。この実装・受入試験は研究上の承認を意味しない。収集開始前に研究者が問題内容・事前アンケート・運用条件を確認する。
